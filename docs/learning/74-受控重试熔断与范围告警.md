# 受控重试熔断与范围告警

## 30 秒心智模型

R2 崩溃演练证明“进程没了仍能接管”；retry-fault 演练证明“外部失败反复发生时，
系统能按 15/30/60 秒节奏打开 circuit，并在成功 probe 后关闭它”。两者不可互相替代。

这次 alert worker 不能直接启动，因为 outbox 是历史审计队列。`acceptance_run_id` 是
新 recovery outbox 的标签；带 scope 的 worker 在 SQL 领取前筛选它，因此不会把旧消息
误投递到 Telegram。
