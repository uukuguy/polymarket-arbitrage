# 健康读取预算与取消：健康页不能把自己误报成故障

## 30 秒心智模型

`/healthz` 不是一个轻量 ping。它读取 Structure、Quote、incident、容量等持久证据。
当 Structure 正在写入时，完整读取约需三秒；若预算只有 0.8 秒，健康页会先超时并把
自己报告为 P1，然后唯一读 worker 继续占用，后来的巡检又看到“读槽饱和”。

正确边界不是无限延长等待：本系统给正常完整投影四秒，并把最重的 generation 查询连接
登记给 deadline。正常写压得到完整真相；真的阻塞则被中断并明确报告读模型 P1。

## 代码地图

- `src/polyarb/http/health.py:_health_response` — 统一健康预算和 P1 envelope。
- `src/polyarb/storage/sqlite_store.py:structure_generation_status` — 只读连接可被
  health deadline 登记，并在该模式用短 busy timeout。
- `src/polyarb/http/opportunity_read_health.py:BoundedReadLane` — 只有一个健康 worker，
  防止慢读无限排队。
