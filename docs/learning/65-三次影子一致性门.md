# 三次影子一致性门：为什么一次成功不能切换

## 30 秒心智模型

一次 Structure/Quote shadow 成功只能证明“这次没坏”。它不能证明迁移路径在
重复运行、不同 lease、不同 worker 下仍然不改 legacy truth。因此 pointer
switch 前必须有三次独立 run 的同构证据。

每次都把 legacy 与 transactional 两边绑成一张不可含糊的对账单：来源身份、
冻结 bundle、六类 Structure 行数、Quote universe、manifest，以及 legacy
pointer mutation 数。任何一个字段不一致，或 mutation 非零，都是 FAIL。

## 证据形状

```json
{
  "runs": [{
    "run_id": "shadow-001",
    "legacy": {
      "source_identity": {"publication_id": "…", "window_id": "…", "snapshot_id": 42,
                          "comparison_receipt_digest": "<sha256>"},
      "bundle_digest": "<sha256>",
      "component_counts": {"events": 0, "event_tags": 0, "memberships": 0,
                           "group_truth": 0, "markets": 0, "issues": 0},
      "quote_universe_hash": "<sha256>"
    },
    "transactional": {"…": "同构字段", "manifest_digest": "<sha256>",
                        "legacy_pointer_mutations": 0}
  }]
}
```

实际文件必须有三条，而不是把同一条复制三遍：`run_id` 唯一是最低防线，运行
时间/worker/lease 证据则由指定云环境的采集记录提供。

## 运行方式

```bash
make control-plane-verify-shadow-parity evidence=shadow-parity.json
```

PASS 只说明“这三次 shadow 达到可申请可逆切换的证据门”。它不执行切换，也
不表示已经获准切换。
