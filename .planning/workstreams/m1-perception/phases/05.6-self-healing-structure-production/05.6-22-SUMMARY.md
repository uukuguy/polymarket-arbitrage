# Plan 05.6-22 Summary: Preserve Quote timeout operator diagnosis

- Production dashboard inspection found a durable P1 Quote-collection timeout
  with `diagnosis=null` even though its evidence contained impact, automatic
  retry, operator action, failure reason, and a valid 180.0-second deadline.
- The read projection had incorrectly required an integer deadline while the
  production collector records timeout budgets as floats. It now accepts only
  finite positive numeric deadlines and normalizes them in the public,
  credential-free diagnosis.
- RED/GREEN coverage uses the real integral-float deadline shape and proves
  the console API keeps severity, deadline, and operator action visible.
