# Plan 05.6-06 Summary: Persist generation read activation

## Root cause

The approved machine-level `POLYARB_STRUCTURE_GENERATION_READ_MODE=generation`
was overwritten by the next standard `make deploy`, because `fly.toml` remained
the durable source of deployment environment with `legacy` configured.

## Delivered

- Persisted the user-authorized production mode as
  `POLYARB_STRUCTURE_GENERATION_READ_MODE = "generation"` in `fly.toml`.
- Quote worker remains explicitly disabled; this change activates only the
  authenticated Structure truth reader.

## Verification gate

Deploy through `make deploy`, then prove the runtime environment is generation,
`/health` anchors to snapshot 884 through the certified pointer, and the app
machine returns to 1/1 checks before Quote activation is considered.
