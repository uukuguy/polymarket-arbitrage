# Plan 05.6-265 Summary: Commission Recurring Quote Recovery

Exact-image commissioning exposed a real contract gap: PostgreSQL batch identities carried the
new recurring Quote generation digest, but the immutable R2 input header did not. A restarted
Quote or Opportunity worker therefore reconstructed a legacy job key from the parent Structure
digest and rejected the otherwise valid successor. The canonical input artifact now carries
`quote_generation_digest`, with backward-compatible parsing for legacy artifacts, and a distinct
Structure/Quote digest round-trip test protects the boundary.

The stale-Quote commissioning path now uses the real initial `quote-admit` successor and the
real cadence refresh transaction. It persists Q1, repeats the same-bucket request to prove no
duplicate relation, stops at the stage boundary before any batch or manifest exists, and then
resumes the exact runnable generation through Quote and Opportunity publication. Q0 remains
quarantined and cannot write business facts.

Commissioning prerequisites were also repaired to certify real Structure manifests before CLOB
attacks. Structure certification now checks immutable range/count/manifest validity before the
successor serialization gate: corrupt candidates quarantine immediately, while valid candidates
wait behind an unfinished Quote or Opportunity chain.

Verification passed:

- focused recurring interruption, duplicate-admission, stale-lineage, parity and CLOB attacks
- Quote admission/worker/artifact suites
- qualification lineage regressions
- Ruff and changed-source Pyright with zero errors or warnings

The complete combined PostgreSQL suite found one obsolete synthetic serialization test; it was
upgraded to a valid Structure candidate and passes focused verification. Exact full-suite replay,
OrbStack image build and production rollout follow from this clean commit.
