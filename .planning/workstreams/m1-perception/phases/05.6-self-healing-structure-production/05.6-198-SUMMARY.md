# Plan 05.6-198 Summary — amd64 Worker Image Contract

## Outcome

Pinned both Docker build stages to `linux/amd64`, the architecture of the
formal `polyarb-control-worker` Fly Machines. This prevents an Apple-Silicon
or heterogeneous builder from publishing an arm64 image that the runtime
cannot accept.

## Changed

- `Dockerfile`: both builder and runtime `FROM` stages explicitly select
  `linux/amd64`.
