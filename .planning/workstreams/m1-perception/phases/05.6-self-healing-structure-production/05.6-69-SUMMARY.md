# 05.6-69 Summary — M1 transactional control-plane schema

## Delivered

- Added additive Alembic revision `009`, chained from `008`, for the durable
  M1 job, attempt, checkpoint, publication, incident, alert-outbox, and alert
  delivery authority.
- Jobs carry a lease owner and monotonically increasing epoch; indexes support
  runnable claims and expired-lease recovery without scanning all history.
- Checkpoint receipts and incident events have idempotency keys. Incident event
  and channel-level outbox records can therefore be committed atomically by the
  repository introduced in the next slice.
- Added `make control-plane-migrate-test`, which only accepts an explicit test
  DSN and validates `009 -> 008 -> 009`; an absent test DSN exits `77`.

## Boundary

This migration is intentionally not yet applied to production and changes no
SQLite table or current Fly worker. The following repository slice will make
claim/checkpoint/finalize mutations fenced and idempotent before any worker is
cut over.
