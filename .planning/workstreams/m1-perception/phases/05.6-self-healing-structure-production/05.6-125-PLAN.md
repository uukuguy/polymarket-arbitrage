# 05.6-125 Plan — Independent formal runtime watchdog

## Objective

Before any further soak acceptance, page an operator within one minute when
the formal control API is unavailable or an exact business Machine exits.

## Boundaries

- `polyarb-control-alert` reads only the public API and Fly Machine status.
- It never opens Postgres and never restarts, stops, or mutates a Machine.
- It sends direct, transition-only Telegram pages and writes each probe's
  heartbeat to its own Fly logs.

## Verification

- Test API timeout, stopped Machine, healthy state, de-duplication, recovery,
  and heartbeat emission.
- Validate the Fly configuration and observe continuous live 30-second logs.
