# Plan 05.6-266 Summary: Repair Recurring Quote Certifier Wakeup

Production Q1 completed all 140 immutable batch inputs with 140 receipts and 140
terminal-success jobs, yet its certifier remained `waiting`. The direct terminal
wake uses the independent Quote generation correctly, but it deliberately skips
a busy certifier row so producers never block. Its durable recovery sweep still
used the legacy identity rule `quote:<structure_receipt_digest>`, which only
worked while Quote and Structure digests happened to be equal.

The recovery barrier now associates a certifier with the canonical
`<quote-generation>:batch:*` job-key namespace. A real PostgreSQL regression
creates distinct Structure and Quote digests, locks the certifier during the
terminal producer transaction, proves the direct wake is skipped, and requires
the subsequent repair sweep to make that exact recurring certifier claimable.

Verification includes the red-before-green recurring lost-wakeup regression,
the historical legacy-generation repair regression, adjacent concurrent wakeup
coverage, Ruff, and source Pyright. Exact-image production rollout and durable
Q1 self-recovery follow from this code commit.
