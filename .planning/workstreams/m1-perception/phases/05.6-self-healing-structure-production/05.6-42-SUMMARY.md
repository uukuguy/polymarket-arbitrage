# Plan 05.6-42 Summary — bounded health-read cancellation and Dashboard P1

## Outcome

Health reads now retain an interruption path after their HTTP budget expires:
the read lane invokes a caller-provided timeout callback, and the Structure
generation health projection has a SQLite progress callback bound to the same
absolute deadline. A timed-out projection can therefore release the sole health
read slot instead of turning subsequent probes into a sustained saturation loop.

The Perception Dashboard now reads `/healthz` as a first-class contract and
renders `runtime:health_read_lane` as a P1 operator-visibility incident with
the authoritative impact, automatic action, and operator action. An unreadable
health result remains a fault, never a zero-opportunity inference.
