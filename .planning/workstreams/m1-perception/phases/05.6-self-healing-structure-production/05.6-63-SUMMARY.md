# 05.6-63 Summary — Structure writer-busy recovery retry

Structure's event-member sidecar correctly checkpointed on SQLite writer
contention, but returned the deferred checkpoint as a complete scheduler tick.
Production's five-minute scheduler cadence then stretched recovery of a large
window into hours while Quote continuously updated.

A writer-busy checkpoint now remains in the existing bounded five-second defer
loop. Quote keeps its independent SQLite lease and is never preempted; the next
Structure child resumes only from its durable checkpoint. The regression test
proves a deferred child is retried before the normal cadence and that a later
sealed child completes the same tick.
