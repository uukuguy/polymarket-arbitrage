# Plan 05.6-268 Summary: Align the Scoped Connection Contract

`PostgresControlPlane` uses every supplied factory under `with`, but its local
annotation still claimed that the factory returned a bare psycopg connection.
That made the production `ScopedConnectionFactory` appear incompatible to
Pyright even though it is the correct bounded-pool implementation.

The shared type now declares the actual context-manager contract. Direct
psycopg connections remain valid, and the scoped pool no longer needs an unsafe
cast at the daemon entrypoint. The daemon regression test now replaces
`ConnectionPool` itself, asserts the bounded pool arguments and bootstrap
settings, and borrows the sentinel through the same context-manager interface
used in production.

Focused daemon tests, Pyright for the changed production files, Ruff, and the
whitespace check pass. This removes the last review-raised typed merge blocker;
it changes neither database policy nor runtime timeout values.
