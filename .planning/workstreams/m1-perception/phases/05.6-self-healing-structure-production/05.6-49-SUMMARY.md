# 05.6-49 Summary — bounded Quote writer and truthful live progress console

## Outcome

- Removed repeated `PRAGMA journal_mode=WAL` negotiation from the hot Quote
  writer connection. `SQLiteStore.init_schema()` remains the single place that
  establishes persistent WAL mode; the per-run writer now reaches its bounded
  `BEGIN IMMEDIATE` contention path directly.
- Added a regression asserting that Quote writer connections do not perform a
  journal-mode transition, so a competing Structure writer cannot turn the
  15-second writer budget into a 180-second parent hard timeout.
- The Fly-native incident console now renders both the latest Structure child
  checkpoint and the separately durable Structure comparison progress. A
  normal checkpointed child cancellation therefore cannot be mistaken for a
  stalled comparison.

## Operator contract

`/perception/console` exposes the current Quote checkpoint, Structure child
checkpoint, and Structure comparison `phase`, row count, cursor, and checkpoint
timestamp. `read-model-unavailable` is still a visibility incident, never a
zero-incident result. Quote writer contention should terminalize as
`child-persist-timeout`, release the collecting run, and be retried by the
supervised producer rather than waiting for the 180-second hard limit.
