# 05.6-147 Summary — Bound every transactional scheduler turn

## Delivered

- Added a 105-second hard boundary around each awaitable scheduler worker turn.
- A timed-out source worker no longer freezes materialization, certification,
  Quote work, or future lease reclamation; the durable lease remains the sole
  fencing authority.

## Verification

- RED/GREEN: an indefinitely hanging worker yields `timed-out` while the next
  worker still runs.
- Focused M1 source/scheduler/CLI/PostgreSQL suite passed (78 tests).

## Boundary

Cancellation does not grant the timed-out operation receipt authority. A later
lease epoch is required for any durable completion.
