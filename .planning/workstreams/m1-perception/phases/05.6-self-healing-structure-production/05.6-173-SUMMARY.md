# 05.6-173 — staging soak 采样命令

## 完成内容

- `control-plane soak-start` 和 `soak-sample` 从独立的控制面 HTTP endpoint 与
  `flyctl machines list --json` 读取事实，并只接受操作者显式列出的 exact machine ID。
  其路径不依赖数据库 DSN，且不会写 job/receipt、移动指针或变更 Fly machine。
- `soak-verify` 在本地 fail-closed 验证 JSONL 证据；将其暴露为三个 Makefile 入口，支持
  逗号分隔的 machine ID，避免操作者重写长 CLI。
- 兼容实际已登录的 Fly CLI：单机 `machine status` 不支持 JSON，改用一次只读的
  `machines list --json` 并在本地筛选，因此不会解析表格输出或误认其他机器。
