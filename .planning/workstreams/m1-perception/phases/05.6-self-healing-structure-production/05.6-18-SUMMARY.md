# Plan 05.6-18 Summary: Open producer P1 alert chain

- Root cause: a durable Structure P1 appeared in the Fly incident console, but
  the common health projection hid it as `0 / disabled` whenever optional
  Candidate recovery was off. Polywatch therefore emitted a false `L1 ok`.
- `/health` and `/healthz` now preserve every open P1 as a failed
  `perception:open_incidents` check, with bounded `p1_count` and exact
  `p1_scopes`. Non-P1 optional recovery behavior remains unchanged.
- Polywatch treats that failed P1 projection as a five-minute alert and sends
  operators to `/perception/console`; only the existing certified producer
  success lifecycle can remove the durable incident.
- RED/GREEN regression covers both the health projection and a fresh-legacy-
  age snapshot that still has an open Structure P1. Focused checks and the
  health/watcher/incident regression suites were run before deployment.
