# 05.6-219 Summary — Make directed attacks cleanup-safe and evidence-collectable

## Outcome

- One typed runner now owns disposable exact-image attack stage ordering without
  adding an all-experiment timeout.
- Every stage is written as an exclusive, append-only artifact bound to the
  exact experiment, release, config, node and attack identity.
- Once injection succeeds, detection/recovery failures still execute cleanup.
  If both the experiment and cleanup fail, both exceptions survive for diagnosis.
- One collector assembles eight normal turns, all 66 node-level attack proofs
  and final E2E lineage, then calls the same fail-closed verifier before writing
  the canonical commissioning envelope.

## Interruption and recovery boundary

- A partial evidence directory is durable audit evidence but is never resumable
  into a success proof by overwriting files. A new experiment gets a new
  identity/directory after cleanup.
- The runner has no arbitrary wall-clock wrapper. Each adapter must use the
  provider, database, lease, progress and recovery policies whose behavior it
  is proving.
- The disposable runner rejects all production-canary contracts. Gamma/CLOB
  canaries require a separate scoped adapter and authority boundary.

## Operator interface

- `make m1-production-commissioning-assemble evidence_root=<dir>
  expected_release=<sha> expected_config=<sha256:id>` produces an envelope only
  when the evidence tree is complete and internally consistent.
- The existing verify target independently revalidates the assembled bytes.
