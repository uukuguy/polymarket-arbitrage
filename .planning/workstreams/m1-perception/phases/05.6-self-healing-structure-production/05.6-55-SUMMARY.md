# 05.6-55 Summary — Dashboard Structure recovery progress

The Fly-native incident console now reads and renders the latest durable
`structure_sync_windows` projection beside the latest Structure child
checkpoint.  Operators can distinguish a stopped child from an active
resumable recovery by inspecting its status, committed event/market page
counts, cursors, checkpoint timestamp, publication id, and failure reason.

The read uses the existing bounded incident lane and read-only projection; it
does not start work, mutate recovery state, or infer progress from logs.
Tests prove both the no-window and exact durable-window cases, with console
and lint coverage required before deployment.
