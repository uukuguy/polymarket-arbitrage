# Plan 05.6-23 Summary: Expose Quote certification failures

- A Quote child that completes successfully is not production success until its
  result is certified against the current Structure publication. Previously a
  stale-universe rejection was logged and retried, but had no durable incident
  for the Dashboard or Polywatch alert path.
- The worker now records every post-child pipeline failure. A stale Structure
  universe becomes a P1 `quote-projection-failure` with the current attempt
  and run identity, explicit impact, automatic wait-for-publication-and-retry
  action, and the Structure publication checkpoint as its operator next step.
- A subsequent certified Quote run continues to verify this incident using the
  existing durable recovery proof; no manual clear or silent downgrade occurs.
- Focused RED/GREEN tests plus Quote worker, lifecycle, and wiring regressions
  pass; ruff and the scoped diff check pass.
