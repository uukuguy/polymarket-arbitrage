## Open gate

A newly certified Structure currently invalidates the previous opportunity
feed until the matching Quote commits. Production measured one 93-second
refresh window in which L1 health remained HTTP 200/warn but the opportunity
endpoint returned 503. The recommended repair is an atomic double buffer:
continue serving exactly one prior complete revision while its Quote remains
within the existing 300-second SLA, mark it refreshing, and atomically replace
it with the new complete revision. Partial projections and data older than the
hard SLA remain forbidden.

The user approved the recommended direction. The self-reviewed written contract
is committed at `7fa4004` in
`docs/superpowers/specs/2026-08-01-m1-opportunity-feed-double-buffer-design.md`.
It is not implemented: the mandatory written-spec review, implementation plan,
TDD changes, and natural production handoff proof remain open. Plan 05.6-02 and
the phase therefore remain in progress.
