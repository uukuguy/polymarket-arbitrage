# Plan 05.6-46 Summary — Dashboard live recovery checkpoints

## Outcome

The Perception Dashboard now reads the independent producer-progress endpoint
and renders the current durable Quote and Structure checkpoint beside P1
incidents. The panel includes stage, outcome, elapsed time, Structure chunk
count, automatic action, and operator action.

The progress read is intentionally optional: an unavailable checkpoint does
not turn the entire Dashboard into an unavailable page or erase the durable
incident record.

## Verification

- Dashboard TypeScript compilation passes.
- Prettier and diff checks pass.
- The M1 operator manual describes the recovery-reading procedure and its
  no-false-all-clear boundary.

## Deployment follow-up

Deploy to the Dashboard once a valid non-interactive Vercel deployment
credential is available. The Fly-native incident console already exposes the
same endpoint and remains the live operator fallback.
