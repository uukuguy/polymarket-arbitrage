## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
| --- | --- | --- | --- |
| Manual topology changes during a qualifying run | A credential or Machine update restarts or gaps independent evidence and invalidates acceptance. | blocking | Verify only; if a repair is necessary, record the failure and start a new uniquely named baseline afterwards. |
| Unfiltered `flyctl machine update` output | The CLI prints a full machine configuration diff, including injected secret values. | blocking | Capture both stdout and stderr for secret-bearing updates; never surface a machine diff. Revoke any exposed token before continuing. |
| `.env` Fly-token shadowing | An obsolete `FLY_API_TOKEN` can override the authenticated Fly CLI and make sibling apps appear missing. | advisory | After sourcing `.env`, run `unset FLY_API_TOKEN FLY_ACCESS_TOKEN` before `flyctl`. |
