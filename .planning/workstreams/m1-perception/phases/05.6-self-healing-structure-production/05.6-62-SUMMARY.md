# 05.6-62 Summary — health read budget and cancellation

Production showed that a complete health projection during Structure writes
needs approximately three seconds. The 0.8-second endpoint deadline generated
a false `read-model-unavailable` P1 and left the one read lane occupied after
the response.

The health budget is now four seconds. The heavyweight Structure generation
query registers its read connection with the health deadline and uses a
250-millisecond busy timeout in that bounded mode. Real saturation still
returns the existing P1 envelope; normal Structure pressure can now report
the actual recovery state.
