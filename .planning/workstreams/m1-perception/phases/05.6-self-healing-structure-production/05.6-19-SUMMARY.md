# Plan 05.6-19 Summary: Quote supervisor recovery transition

- Production logs showed `InvalidIncidentTransitionError` in the Quote
  supervisor, despite the parent daemon continuing to run.
- Root cause: on restart, the supervisor correctly moved an exhausted Quote
  event from `escalated` to `recovering`; reconciling an abandoned child then
  rediscovered that same event but unconditionally attempted
  `recovering -> classified`, an illegal lifecycle edge.
- Existing recovering incidents are now reused and contained for the bounded
  retry path. A genuinely newly detected incident still follows
  detected -> classified -> contained unchanged.
- RED/GREEN regression reproduces the exact restart-plus-abandoned sequence;
  supervisor, daemon-shutdown, and Quote incident suites plus Ruff pass before
  production deployment.
