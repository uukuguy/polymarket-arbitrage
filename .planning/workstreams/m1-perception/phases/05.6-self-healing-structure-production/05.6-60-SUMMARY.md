# 05.6-60 Summary — Structure bootstrap query deadline

The online bootstrap outer loop had 45-second cooperative checks, but one
synchronous SQLite call could still run past them and reach the 75-second
parent watchdog. Production observed exactly that failure after otherwise
healthy small-chunk progress.

`advance_structure_event_market_backfill` now supports a SQLite progress
handler deadline. The online caller caps one operation at five seconds and
translates the expected interruption into a normal durable `bootstrap`
checkpoint. No partial transaction is committed. Scheduler stage parsing now
records `bootstrap`, so a remaining failure is actionable rather than an empty
stage timeout.
