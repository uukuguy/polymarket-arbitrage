# 05.6-175 — 自动化 staging soak 采样

## 完成内容

- 安装用户级 LaunchAgent `com.polyarb.m1-transactional-soak-sampler`：每 600 秒运行一次
  `make control-plane-soak-sample`，采样后退出，不启动常驻数据 worker。
- 任务只读取独立 control API 和已显式列出的五个 Fly machine ID；不读取 secret、不写 job、
  receipt 或 pointer。
- 首次 RunAtLoad 已成功，evidence JSONL 从恢复后的两条人工样本增长为四条记录；LaunchAgent
  最后退出码为 0。
- 忽略本地 sampler stdout/stderr，保留 JSONL 作为最终可提交的不可篡改验收事实。

## 运维

- 检查：`launchctl print gui/501/com.polyarb.m1-transactional-soak-sampler`
- 停止：`launchctl bootout gui/501/com.polyarb.m1-transactional-soak-sampler`
- JSONL 仍必须在 24 小时后使用 `make control-plane-soak-verify evidence=<path>` fail-closed
  验证；任何超过 900 秒的采样间隔都会使该窗口失败。
