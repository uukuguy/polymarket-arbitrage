# Plan 05.6-28 Summary: Fail contended comparison writes promptly

- A production comparison child returned in 55 seconds while waiting on the
  shared SQLite writer, which remained below the hard kill limit but exceeded
  its cooperative execution budget.
- Comparison checkpoint commits now use the five-second production writer-lock
  deadline already used for atomic pointer switching.
- A contended low-priority comparison write therefore becomes a classified,
  retryable scheduler failure instead of consuming the child budget in a
  silent SQLite wait.
