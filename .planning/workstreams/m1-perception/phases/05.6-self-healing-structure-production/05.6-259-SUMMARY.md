# Plan 05.6-259 Summary: Separate Universe Discovery from Executable Quote Runs

Production required roughly 35 minutes for the latest capped keyset traversal while the
qualification policy requires executable products within 900 seconds. The same code made Quote
identity equal to Structure digest, preventing another Quote or Opportunity until the next full
window. The contradiction is deterministic and cannot be repaired by retry or timeout tuning.

The approved design restores the project's earlier two-clock contract in the transactional
runtime. Structure remains complete known-universe truth; recurring immutable Quote runs collect
executable prices against it every 300-second admission cadence; every Quote releases its own
Opportunity projection. A new relation carries exact lineage so qualification never guesses a
Structure identity from a Quote digest.

The implementation is divided into migration/identity, durable admission, concurrency ordering,
lineage readers, coordinator cadence, and exact-image production proof. No code or deployment
claim is included in this design Summary; Task 1 starts with a failing identity and migration test.
