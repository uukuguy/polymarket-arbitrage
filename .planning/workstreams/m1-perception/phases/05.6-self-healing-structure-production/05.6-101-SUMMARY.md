# 05.6-101 Summary — Bound and rotate transactional worker turns

## Delivered

- Added a library-only `TransactionalControlPlaneScheduler` that runs at most
  `max_turns` worker turns per tick.
- The scheduler serializes overlapping ticks within one process and rotates
  the worker starting point across ticks, so a bounded Structure-first tick
  cannot starve Quote work.
- Distributed correctness remains with the existing Postgres claim/lease/epoch
  fence: concurrent schedulers may attempt work, but cannot own the same job
  effect.

## Verification

- Contract proves a two-turn tick executes only the bounded Structure pair and
  the following tick rotates to the Quote pair.
- Scheduler/Structure/Postgres/CLI regression: 35 passed; Ruff passes.

## Boundary

There is intentionally no CLI, service loop, timer, or deploy wiring yet. A
future guarded operator command must construct workers from configured DSN/R2
credentials and invoke one tick before any persistent scheduler is authorized.
