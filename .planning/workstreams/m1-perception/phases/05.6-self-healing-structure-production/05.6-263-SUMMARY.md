# Plan 05.6-263 Summary: Read Quote Lineage from Durable Relation

`current_quote_projection_inputs` now joins `quote:current` directly to
`m1_quote_generation_inputs` and returns the relation's exact Structure parent. Opportunity
publication uses that same relation to verify that the requested Quote and Structure manifests
are both certified and actually related; supplying two independently valid but unrelated
manifests no longer passes validation.

Qualification Structure freshness now joins Quote pointer → Quote lineage → Structure manifest.
The old `substr(pointer.generation_key, 7)` inference is gone. If the lineage or parent manifest
is missing, the bounded query returns no row and the existing freshness wrapper writes an
explicit `evidence.gap` fact. Quote and Opportunity freshness bounds remain 900 seconds.

The disposable end-to-end commissioning reader was also changed from Quote digest parsing to
the exact lineage table. A real PostgreSQL regression publishes Q0 and Q1 over the same
Structure, projects both independently, and proves the current Opportunity pointer and rows
move to Q1 while retaining both immutable projection records.
