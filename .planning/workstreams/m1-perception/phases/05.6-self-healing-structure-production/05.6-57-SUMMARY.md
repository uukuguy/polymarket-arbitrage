# 05.6-57 Summary — Structure slice deadline recovery

The online Structure synchronizer now derives each Gamma page request timeout
from the remaining 45-second cooperative slice after reserving the bounded
SQLite commit window. When no safe page budget remains, it returns a durable
checkpoint instead of beginning a late request that can only be killed by the
75-second parent watchdog.

This directly repairs the production symptom where `gamma-markets` page counts
advanced but every long slice terminalized as `snapshot-subprocess-timeout`.
The cursor remains authoritative because it advances only after the per-page
commit; a deferred late page is retried from the same cursor next cycle.

The regression test fixes the clock at second 37 of a 45-second slice and
proves that the page receives a three-second budget, while the existing elapsed
slice test now asserts immediate normal checkpointing after the first page.
