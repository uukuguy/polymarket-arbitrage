# 05.6-106 Summary — Add the signal-safe transactional scheduler service

## Delivered

- Added `TransactionalControlPlaneScheduler.run_until_stopped`, a fixed-cadence
  wrapper around bounded, lease-fenced ticks. It emits every completed tick via
  a caller callback and stops only through a caller-owned event.
- Added default-off `control-plane serve --enable` and
  `make control-plane-serve enable=1`. SIGINT/SIGTERM request graceful stop;
  tick outcomes are emitted as JSON lines and final shutdown reports tick count.
- The service wrapper owns no cross-process correctness: Postgres leases and
  epochs remain the authority, and the target contains no Fly/deployment wiring.

## Verification

- Scheduler service contract proves one emitted bounded tick and immediate
  signal-event shutdown without sleeping.
- CLI contracts prove acknowledgement-before-connect and correct scheduler
  service composition.
- Full transactional regression, Ruff, dry-run Make command and planning gate
  run before commit.

## Boundary

- This is a deployable process primitive, not a deployment. It must only be
  started after named-environment preflight, revision-009 migration and
  shadow-only acceptance evidence.
