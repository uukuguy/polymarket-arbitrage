# 05.6-112 Summary — Fetch Structure source pages transactionally

## Delivered

- Added `TransactionalStructureSourceWorker`: it claims one `structure-fetch`
  page, calls exactly one Gamma event or market page API, creates an immutable
  NDJSON source artifact, PUT+HEAD authenticates it in R2, then asks the
  revision-010 control plane to atomically record the page and release its
  legal successor.
- A Gamma failure makes only the owned source page retryable; it cannot mutate
  the durable cursor or release another page.
- Added real PostgreSQL crash-window evidence for death after R2 upload and
  before source receipt. A replacement worker reclaims the lease, refetches
  the same cursor, and produces one durable receipt.

## Verification

- Unit contracts prove one-page event dispatch, canonical artifact receipt
  fields, and retry isolation on a Gamma timeout.
- Real Postgres contract proves R2-upload-before-receipt takeover with two
  fetches/two idempotent uploads and exactly one page receipt.
- Focused source worker and PostgreSQL contracts plus Ruff pass.

## Boundary

The source-window worker now owns upstream pages, but a completed window does
not yet materialize the current six-component Structure bundle. Legacy SQLite
remains shadow-only until the next slice re-parses sealed R2 page evidence,
derives the bundle, and feeds existing normalize/certify/Quote jobs.
