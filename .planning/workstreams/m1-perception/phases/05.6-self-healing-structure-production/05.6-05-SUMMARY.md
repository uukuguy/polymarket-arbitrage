# Plan 05.6-05 Summary: Generation market-truth health

## Root cause

After the authenticated generation pointer for snapshot 884 was published and
the user authorized `READ_MODE=generation`, `/health` still reported legacy
snapshot 845 as its market-truth anchor. `read_market_truth_health()` read only
`snapshot_source_coverage`, which is intentionally absent for the independent
generation publication path.

## Delivered

- In generation read mode, health now reads only `current_structure_generation`
  joined to a published, valid Structure snapshot.
- The pointer must be `bounded-complete` and carry a 64-character comparison
  receipt; otherwise health fails closed and never falls back to legacy truth.
- Market and event counts come from the pointer's authenticated committed
  counts, preserving the health API's latest-attempt contract.

## Verification

- Red: a published generation pointer with incomplete legacy coverage raised
  the missing mode-aware API error.
- Green: the new pointer contract test and all market-truth health tests pass.
- Full `test_health_endpoint.py` completed with no failing test output; Ruff
  passed for the changed files.

## Remaining production gate

Deploy this health repair after the read-mode machine update, then verify
`/health` anchors to generation snapshot 884. Quote remains disabled until its
separate explicit activation and end-to-end candidate/alert verification.
