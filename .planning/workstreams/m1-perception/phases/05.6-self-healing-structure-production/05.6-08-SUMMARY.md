# Plan 05.6-08 Summary: Supervised Quote feed handoff

## Root cause

The production supervisor isolates Quote collection from the HTTP parent. The
child produced certified Quote runs and 17 candidate opportunities, but the
HTTP parent had no resident `QuoteWorkerRuntime`; `/arbitrage/opportunities`
therefore returned 503 despite durable source evidence.

## Delivered

- Extracted a read-only certified-feed loader from the Quote worker.
- On a cold HTTP cache, the endpoint uses the loader under a 2.5-second budget
  and atomically restores the certified feed into its resident runtime.
- Main wires this loader only when public Quote collection is enabled; no CLOB
  request, order, wallet, signer, or structure mutation is introduced.
- In supervised topology, the HTTP parent preloads and refreshes that durable
  feed every 15 seconds; collection remains exclusively in the isolated child.

## Verification

- Red/green HTTP contract test proves a parent with an empty runtime serves a
  feed published by an isolated producer; an additional wiring test proves the
  parent hydrates without invoking collection.
- Related Quote wiring and opportunity endpoint suite: 68 passed.
- Changed-file Ruff: passed.

## Remaining production gate

Deploy this handoff fix and obtain repeated public HTTP 200 evidence with the
durable candidate identities. Then complete the separate bounded cleanup-child
repair before declaring continuous-operation acceptance.
