# 05.6-213 Summary — Align watchdog and API health authority

## Outcome

- The independent runtime watchdog no longer treats a long, durably progressing
  attempt as stalled merely because the aggregate succeeded-job count is flat
  for five minutes.
- Active-task projections now expose snapshot-relative heartbeat-missing and
  progress-overdue values. Heartbeat-missing is derived from the persisted
  three-period incident boundary, not the earlier heartbeat-due action time.
  The watchdog trusts those persisted per-attempt deadlines and
  uses stage/current/total tokens only as a rolling-upgrade fallback for an old
  API payload.
- Runnable work with no active attempt retains the queue-level stalled-progress
  fallback, so the repair does not turn a genuinely abandoned queue green.
- The control API now separates process liveness (`/healthz`, always HTTP 200)
  from strict Postgres readiness (`/health`, typed HTTP 503). Fly therefore keeps
  the sole operator API Machine routed during a transient database failure while
  `/health`, `/perception/control-plane`, and the independent watchdog continue
  to expose the failure.

## Production evidence that triggered the repair

- A Structure certifier continuously advanced `verify-parity` progress and
  refreshed heartbeat, lease, progress, and attempt facts, but the deployed
  watchdog continued reporting `control-api:job-progress-stalled:310s` because
  it observed only the aggregate succeeded count.
- The sole `polyarb-control-api` Machine remained started without an OOM or
  process restart, while Fly logs showed repeated 15–60 second health-check
  removal/recovery windows. The platform probe was coupled to Postgres
  readiness, so a transient database failure removed the only route to the
  application's typed unavailable response.
- The old `structure-materialize` retryable is not blocked by an in-process
  serial lane. Scheduler lanes are concurrent; the database generation-order
  guard intentionally holds materialization behind unfinished prior
  normalize/certify generations.
