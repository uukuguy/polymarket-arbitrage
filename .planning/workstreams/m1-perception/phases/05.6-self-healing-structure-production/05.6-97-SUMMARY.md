# 05.6-97 Summary — Gate reversible Structure shadow publication

## Delivered

- Added `publish_structure_shadow`, the only repository path that can move
  `structure:current:shadow`.
- It accepts only a manifest produced by that generation's
  `structure-certify` job.  Uncertified/incomplete generations leave the
  shadow pointer absent.
- Updating an existing shadow pointer retains the prior generation in
  `expected_generation_key`, providing a durable reversible predecessor.
  The method never reads or writes `structure:current`, the legacy truth.

## Verification

- Real Postgres test proves rejection before certification, success after a
  matching certifier manifest, an empty legacy-pointer namespace, and the
  isolated shadow pointer identity.
- Focused Structure/control-plane suite: 40 passed; Ruff passes.

## Boundary

This is deliberately only the persistence gate. A distinct default-off,
explicitly authorized operator route and observability must be added before
any real shadow pointer action. No production pointer has been changed.
