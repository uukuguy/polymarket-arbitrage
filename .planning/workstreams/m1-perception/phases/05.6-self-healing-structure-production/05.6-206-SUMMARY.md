## Fault-matrix result

The canonical matrix covers task exception, R2 timeout/hang, heartbeat loss,
progress stall, stale owner, circuit probe, process exit, Machine restart
decision, database/event-writer failure, watchdog failure, duplicate delivery,
and stale action.

Every row asserts bounded detection latency, incident transition, recovery
action/result, fence result, recovery state, Dashboard source projection, and
qualification ingress/decode/replay impact. The matrix exposed production-code
qualification defects; none were filtered out of the evaluator.

## Observe-only proof boundary

- `POLYARB_RUNTIME_RECOVERY_MODE` is a closed enum and defaults to
  `observe-only`.
- `--enable` allows the controller command to run; it does not select execute
  mode.
- Observe-only evaluates all bounded candidates so simultaneous failures remain
  visible even though execute mode schedules at most one action per turn.
- An empty candidate set writes an idle fact, so a silent controller cannot be
  confused with a healthy controller.
- `make runtime-observe-verify` is read-only and checks at least 1,800 seconds
  by default, freshness/gaps, exact active controller identity, runtime parity,
  canonical digests/replay, and zero overlapping recovery actions.
