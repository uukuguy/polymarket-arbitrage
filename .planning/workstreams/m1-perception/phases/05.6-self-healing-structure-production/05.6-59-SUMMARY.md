# 05.6-59 Summary — Structure bootstrap slice bound

Production recovery reached a completed Structure window but still timed out at
75 seconds while deriving event→market relationship staging. The former 500-row
bootstrap unit and 120-second SQLite writer wait allowed one synchronous unit to
outlive the 45-second cooperative child slice.

Online bootstrap now commits at most 50 events and 50 relationships per unit,
with writer waiting capped at five seconds and by remaining slice time. The
durable cursor, staging truth, and restart semantics stay unchanged. A
time-controlled 60-event regression proves the first online unit commits only
50 rows and receives the five-second writer cap.

The same validation exposed an ordinal-index ordering defect for old worker
schemas. `init_structure_sync_schema()` now additively creates
`source_ordinal` before running the DDL that creates the dependent index, so a
legacy volume still reaches the resumable migration path.
