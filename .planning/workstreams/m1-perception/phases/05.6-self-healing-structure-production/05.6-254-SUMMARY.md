# Plan 05.6-254 Summary: Bind Watchdog Health to the Producing Node

Production exposed two coupled false-health defects while an otherwise healthy
Structure certifier advanced through its 1,088 parity checks.

## Root causes

`CloudUsageGate` treated any historical `succeeded` job as active collection.
Because that counter never decreases, a 15-minute cloud-usage threshold became
a permanent false failure whenever the pipeline correctly backpressured new
Gamma admission during normalize or certify.

The independent watchdog did detect this state, but its private writer failed
on `m1_alert_outbox` with `InsufficientPrivilege`. The incident/event/outbox
transaction rolled back, leaving the operator API's current-watchdog projection
null even while the watchdog log reported unhealthy every 30 seconds.

## Repair

- Cloud-usage enforcement now selects only current `structure-fetch` active
  tasks. A new fetch owns one 15-minute grace; an overdue fetch without a fresh
  metered input fact fails closed. Certifier, normalizer and historical success
  counts cannot impersonate provider ingress.
- Revision 037 conditionally repairs the pre-scoped legacy
  `m1_runtime_event_writer` login with exactly SELECT and INSERT on
  `public.m1_alert_outbox`. Fresh installations without that legacy role remain
  migratable. Downgrade revokes the same pair.
- Schema identity advances to revision 037, preventing release rollout or role
  preflight from accepting code against the old database head.

## Verification

- TDD proved certifier/no-source work is healthy, a newly started source fetch
  owns grace, and only overdue missing/stale source metering fails.
- A real OrbStack PostgreSQL 16 upgrade/downgrade proved SELECT/INSERT become
  true and UPDATE/DELETE remain false.
- Watchdog, writer, CLI, rollout, database-role, Alembic schema, Ruff and Pyright
  focused gates pass.

## Production boundary

The code and migration are locally verified but not yet deployed. Production
remains at revision 036 while the old coordinator completes the active Structure
certifier. Qualification is stopped on the new image/release identity. The
current data plane remains at zero open circuits and zero expired leases.
