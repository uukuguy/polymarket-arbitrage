# Plan 05.6-260 Summary: Add Authoritative Quote Run Lineage

`QuoteRunIdentity` canonically hashes the exact Structure generation, universe hash,
300-second cadence and cadence bucket. `QuoteBatchSpec` can now bind batch/job identity to
that run digest while retaining the old Structure-digest behavior for callers not yet migrated.

Alembic revision 038 creates `m1_quote_generation_inputs`. Its Structure parent is an exact
foreign key to a certified manifest; Quote generation, Structure generation and universe fields
have strict lowercase digest checks; cadence fields are both absent for legacy rows or both
valid for recurring rows. The migration refuses an orphan legacy Quote, backfills valid existing
manifests, removes PUBLIC authority and grants the qualification capability SELECT only.

The real PostgreSQL 16 test upgrades through revision 037, seeds FK-valid legacy manifests,
upgrades to 038, verifies the exact lineage/privilege row, and downgrades cleanly. No production
migration has run. The next task threads this identity through durable Quote admission.
