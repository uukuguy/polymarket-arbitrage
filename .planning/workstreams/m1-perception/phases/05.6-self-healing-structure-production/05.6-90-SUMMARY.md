# 05.6-90 Summary — Run fenced transactional Structure ranges

## Delivered

- Added `TransactionalStructureWorker`, which claims at most one
  `structure-normalize` job and has no SQLite dependency.
- It downloads the admitted R2 source bundle, authenticates its digest and
  canonical form, filters only the worker's stable-key half-open range, then
  uploads and HEAD-verifies a content-addressed normalized range artifact.
- A prior typed range receipt is recovered by simply finishing the claimed
  attempt; no source bundle is fetched or rebuilt during takeover.
- Added typed `StructureRangeReceipt` reads and a reusable authenticated R2
  range upload helper.  Malformed immutable input quarantines the job; remote
  failures remain retryable.
