# 05.6-76 Summary — Transactional Quote generation foundation

## Delivered

- Added immutable `QuoteBatchSpec` identities: normalized token range, range
  digest, generation key, batch job key, and input identity all derive from
  the certified Structure receipt and universe hash.
- Added idempotent Quote generation admission into the fenced Postgres control
  plane. Every deterministic range has one `quote-batch` job and the generation
  has one later `quote-certify` job.
- Extended additive Alembic 009 with `m1_quote_batch_receipts`. A batch receipt,
  its fenced checkpoint, and its attempt transition commit in one Postgres
  transaction; a stale worker cannot write and an authenticated retry has no
  duplicate durable effect.
- Added terminal certification. It refuses a missing, mismatched, or stale
  batch set; only full receipt coverage can create an immutable Quote manifest
  and atomically write the durable `quote:current` publication pointer.

## Verification

- RED/GREEN contracts cover normalized batch identity, idempotent admission,
  stale lease rejection, no pointer on incomplete coverage, and one pointer on
  full coverage.
- `uv run pytest tests/alembic/test_009.py tests/m1-perception/test_control_plane_postgres.py -v` — 12 passed against PostgreSQL 16.
- Changed-file Ruff and targeted `git diff --check` passed.

## Boundary

This is only the transactional authority slice. No Quote CLOB worker claims
these jobs yet; no legacy SQLite scanner pointer, production migration, deploy,
or external service state changed. The next slice is a disabled-by-default
worker that claims one range, retries only that range, and exposes control-plane
batch state to operators.
