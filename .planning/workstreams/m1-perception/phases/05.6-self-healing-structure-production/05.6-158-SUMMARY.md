# 05.6-158 Summary — Normalize omitted nested neg-risk flags from sealed parent truth

## Delivered

- An active event-only child that omits `negRisk` now normalizes to false when
  its parent has no neg-risk group, and to true only when its parent supplies a
  group identity.
- Explicit child values remain untouched and are still checked against the
  sealed event membership/group truth.

## Why

- After excluding closed children, staging exposed open market `691547`: the
  embedded event response omitted `negRisk`, while the legacy active `/markets`
  stream emits `false`. The normalizer correctly rejected the missing boolean;
  this change reconciles the two source encodings without adding another API
  read.

## Verification

- RED/GREEN regression omits `negRisk` on an open non-neg-risk child and proves
  it becomes the sole published market in the v2 bundle.
- Source bundle/materializer suite (7 tests) and Ruff passed.
