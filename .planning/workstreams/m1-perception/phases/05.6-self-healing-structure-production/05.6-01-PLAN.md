# Plan 05.6-01: Durable self-healing Structure producer

**Goal:** Make interrupted Structure collection resume from durable page truth
and keep recovery active and observable without publishing partial membership.

## Requirements

- [x] Event and market pages commit atomically with opaque successor cursors.
- [x] A restarted worker resumes the exact open window.
- [x] Only complete staged windows enter the existing Structure validator.
- [x] Successful certification atomically binds the published snapshot.
- [x] Bounded point reconciliation delegates to live Gamma.
- [x] Scheduler invokes `structure-sync`, retries recovery after five seconds,
  and never writes a new terminal `PAUSED` state.
- [x] Fixed-vocabulary stage markers survive child timeout diagnostics.
- [x] Strict health exposes sync state, stage and page counts.
- [x] New config, Fly enablement, CLI and Makefile surfaces are tested.
- [x] Focused regression, changed-file Ruff, compile and diff gates pass.
- [x] Operator/learning documentation explains the recovery contract.

## Makefile surface

- `make sync-structure-local`

## Safety

The target writes local Structure state. It performs no CLOB archive, wallet,
order, or production mutation.
