# Plan 05.6-261 Summary: Admit and Publish Recurring Immutable Quote Runs

`admit_due_quote_refresh` now serializes cadence admission, rejects overlapping unfinished
successor work, reads the exact current Quote-to-Structure lineage, and atomically creates one
ordinary run-scoped `quote-admit` job per cadence bucket. Revision 039 moves admission
uniqueness from Structure generation to Quote generation while retaining the exact parent
Structure key on every row.

Quote admission threads the intended Quote run digest into every batch. Batch wakeup,
checkpoint recovery and terminal completion parse both the Quote run and Structure identities;
the certifier loads authoritative lineage from PostgreSQL and verifies every receipt against
that row before pointer CAS. A real PostgreSQL test proves the entire recurring path from due
admission through `quote:current` publication where the Quote digest differs from its Structure
digest.

Commissioning and coverage helpers now certify real Structure prerequisites before exercising
Quote nodes. This preserves revision 038's parent-manifest FK instead of creating synthetic
orphan Quote work. PostgreSQL 16 migration 039 was proven through legacy backfill, two distinct
Quote admissions sharing one Structure, and clean downgrade after removing the extra run.
