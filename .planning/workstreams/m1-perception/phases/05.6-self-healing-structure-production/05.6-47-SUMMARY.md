# Plan 05.6-47 Summary — Quote persistence timeout containment

## Outcome

Production Quote collection no longer delegates its final SQLite writer wait to
the global 120-second busy timeout.  Fly configuration gives CLOB fetch 75
seconds and the Quote writer 15 seconds.  A busy/locked final write is emitted
as a typed `persist-timeout` child envelope, the parent releases the collecting
lease, terminalizes the durable attempt as `child-persist-timeout`, and lets
the existing supervised retry path recover it.

The Dashboard producer card now exposes the durable failure kind, target count,
per-stage timing, and bounded Structure stderr evidence, so this diagnosis is
available without SSH or log inference.

## Verification

- Quote-store writer timeout selection and SQLite-lock classification tests pass.
- Fetch and persist child timeout envelopes both prove parent terminalization.
- Full Quote store/collector/worker test set passes.
- Dashboard TypeScript compilation and Prettier pass.
- `make docs-m1-check` and `make planning-status` pass.

## Deployment follow-up

Deploy the daemon image, then verify at least one completed Quote cycle and
that any writer collision is bounded and visible as `persist-timeout` rather
than an opaque 180-second child timeout.
