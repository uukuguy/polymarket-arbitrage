# 05.6-58 Summary — Structure market ordinal index

Production diagnosis found `commit_structure_market_page` executing
`MAX(source_ordinal)` under `BEGIN IMMEDIATE` against a 104,600-row recovery
window. The primary key indexed market ID rather than ordinal, so this was a
long writer-owned scan and directly explained repeated 75-second child timeouts.

`idx_structure_sync_market_ordinal(window_id, source_ordinal DESC)` is now an
idempotent schema artifact. It changes no staged data or cursor semantics; it
makes the exact existing MAX query use an ordinal-ordered access path. The
schema regression asserts that `EXPLAIN QUERY PLAN` names this index.
