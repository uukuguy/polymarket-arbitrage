# Plan 05.6-43 Summary — truthful Structure recovery schedule

## Outcome

The Structure scheduler now derives and persists timing using the same 75-second
producer-slot envelope that actually bounds the child. It no longer restores a
historic 600-second timeout / 660-second cadence as its effective production
schedule while `_run_snapshot` silently applies 75 seconds.

scheduler and health surface clamp them to the current 75-second slot and the
configured 300-second cadence. The next durable adjustment records the bounded
values, so operators do not need to edit SQLite state manually.
