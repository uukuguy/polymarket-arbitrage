# 05.6-153 Summary — Keep materializer R2 reads off the scheduler loop

## Delivered

- Source-page artifact reads during Structure materialization now execute via
  `asyncio.to_thread`, one page at a time.

## Why

- Synchronous object-store `Body.read()` inside an async worker blocks the
  event loop and prevents the scheduler's turn timeout from taking effect.
  Thread offloading lets the existing 105-second turn boundary cancel the
  await, leave the stale lease fenced, and permit later recovery.
