# 05.6-80 Summary — Quote receipt recovery across lease takeover

## Delivered

- Made an already committed Quote-batch receipt replayable by a replacement
  lease when its immutable result identity matches: range digest, Quote digest,
  artifact key/digest, and successful response count.
- The replacement receives the original receipt epoch as evidence and can use
  its current fence only to finish the abandoned job. A changed artifact or
  response count remains an idempotency conflict.

## Verification

- Real PostgreSQL test covers the exact crash window: first worker records the
  receipt, lease expires before finish, replacement authenticates the result,
  then completes the job under epoch 2.

## Boundary

The worker invocation itself is not wired yet. This recovery primitive exists
so that worker wiring cannot create a permanent checkpointed-job tombstone.
