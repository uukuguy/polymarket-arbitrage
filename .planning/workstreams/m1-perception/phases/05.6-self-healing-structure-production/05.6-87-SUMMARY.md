# 05.6-87 Summary — Authenticated Structure bundle consumption

## Delivered

- Added `parse_structure_bundle_bytes`: it checks the expected SHA-256 before
  parsing, reconstructs the frozen identity and all six component sets, then
  reserializes them canonically to reject substitution or noncanonical bytes.
- A corrupted digest, malformed header/record, wrong component/count, or byte
  ordering mismatch yields a typed `StructureBundleError` before a worker can
  create an output artifact or durable receipt.

## Verification

- The bundle suite now proves authenticated parse/recovery and digest mismatch
  refusal alongside the existing serialization/R2 HEAD contracts.

## Boundary

This validates worker input but does not yet claim a range or write its output
receipt. The next worker slice must keep this verification before its first
fenced effect.
