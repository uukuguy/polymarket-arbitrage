# Plan 05.6-264 Summary: Schedule Recurring Quote Refresh Admission

`TransactionalQuoteRefreshAdmitter` calls only `admit_due_quote_refresh` and returns its durable
decision. The production scheduler installs it as a coordinator lane immediately before the
ordinary Quote admission worker, with a fixed 300-second cadence. It does not inspect Gamma,
read R2, or run Quote batches; the advisory transaction and cadence identity remain the source
of truth when schedulers restart or overlap across processes.

The new `quote-refresh-admit-once` CLI command and `make quote-refresh-admit-once enable=1`
target expose exactly one bounded admission attempt. Both require explicit enablement and a
control-plane DSN. The Make target does not request R2, provider, deployment, Docker, Machine,
wallet or recovery authority.

`operational_snapshot` now joins `quote:current` to authoritative lineage and reports the exact
parent Structure generation, cadence seconds, cadence bucket and calculated next eligibility
timestamp. Legacy immediate Quote generations truthfully show null cadence fields. Missing
lineage fails closed by making the current pointer unavailable rather than reconstructing it
from a digest.
