# 05.6-99 Summary — Freeze stable-key Structure range slices at admission

## Delivered

- Added deterministic stable-key range planning for all six Structure
  components.  Boundaries are computed from the sealed exporter rows before
  jobs exist; every non-empty component is split into fixed-size half-open
  ranges and every empty component retains one zero-row range.
- Added `range_max_rows` to the guarded shadow admission operator (default
  1000). The complete resulting range plan is persisted through normal job
  admission, so retries and replacement workers only recover it from Postgres.
- Range cursors support the legacy numeric validation-issue id while rejecting
  booleans and other ambiguous cursor values.

  slice plan, including the exact cut boundary and empty components.
- Focused Structure/control-plane suite: 45 passed; Ruff passes and Make
