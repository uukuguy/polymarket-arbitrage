# Phase 05.2 Plan 03: Staged M1 Manual Synchronization Guard

Integrated the existing `scripts/check_m1_manual.py --staged` contract into the
repository pre-commit hook without changing the existing plan SUMMARY guard.

## Hook Placement and Behavior

The hook invokes:

```text
uv run python scripts/check_m1_manual.py --staged
```

immediately after `set -euo pipefail`. This placement is intentionally before
commit-subject parsing and `PHASE_PLAN=` so a non-plan-scoped commit or a hook
invocation without a message cannot bypass the staged M1 guard.

The integration preserves the Task 1 classifier and therefore has three
auditable outcomes:

- a staged M1 public-contract change without a staged manual update is blocked;
- the same contract change with a valid staged manual update is allowed;
- unrelated, test-only, and log-only changes exit successfully without manual
  validation output.

Section 10 of the manual now records that enforcement is active. Public changes
with operator impact update the relevant explanation or readiness matrix. A
public change with no operator impact stages a dated sync-log entry explaining
why the workflow is unchanged.

production path families and through the real temporary-repository hook.

prefix and indentation: `checks["name"] =`, `@app.command(...)`, a variable
