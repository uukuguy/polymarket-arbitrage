# Phase 05.2 Plan 01: Offline Manual Contract Checker

Implemented the first H-007 slice: a credential-free checker for the future M1
living manual. The public interfaces are:

- `validate_manual(root: Path, text: str) -> list[str]`
- `classify_staged_impact(paths: list[str], diff: str) -> bool`
- `main(argv: Sequence[str] | None = None) -> int`

The fixture suite covers six contract areas across five focused tests:

1. all ten required numbered headings and verification/current-state metadata;
2. readiness-label allowlisting and seven-column capability rows;
3. Make target existence and local Markdown-link resolution;
4. health marker name/source agreement;
5. dashboard filesystem route/source agreement;
6. narrow staged-impact classification, including negative refactor/test cases.

The validator reads only repository files. It performs no HTTP calls, cloud
operations, credential lookup, or production mutation. The real manual is
deliberately deferred to Plan 05.2-02.

## Deviations

The plan example imported `Sequence` from `typing`; Python 3.12 Ruff rule
UP035 requires `collections.abc.Sequence`, which preserves the exact public
annotation while satisfying repository lint. The fixture also needs a local
`sys.path` bootstrap before the specified `scripts.check_m1_manual` import due
to the preloaded third-party namespace described above.
