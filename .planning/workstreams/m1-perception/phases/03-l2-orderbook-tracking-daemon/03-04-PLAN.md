## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| polyarb-l2 daemon → Polymarket WS endpoint | outbound TLS WebSocket to wss://ws-subscriptions-clob.polymarket.com/ws/market; no auth required (L0 read-only data plane) |
| WS frame parse → on_event callback | untrusted JSON from Polymarket; must defensively handle malformed payloads (JSON validation) |
| Reconnect storm → Polymarket IP-ban | excessive reconnect rate (R5) → Polymarket may rate-limit / temporarily block IP |
| max_size frame cap | 4 MiB limit on inbound WS frames — defends against fat-payload memory pressure (R7) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04-01 | Information Disclosure | WS frame contents logged at DEBUG could leak market data to logs (low-value but unnecessary) | mitigate | Log only frame count + event type per frame; never log full body. Use `logger.debug(f"event type={data.get('type')}")` not `logger.debug(data)`. |
| T-03-04-02 | Tampering | Polymarket WS endpoint could be MITM'd via DNS or compromised TLS | accept | TLS validation by websockets lib default; cert pinning skipped (operational overhead too high for L2 phase). Watchdog catches behavioral anomaly anyway. |
| T-03-04-03 | Repudiation | reconnect events not traceable | mitigate | watchdog emits Sentry breadcrumb `category='l2-ws'` on every state transition; loguru INFO line with state + attempt + backoff seconds. Phase 02.1 P1 double-anchor. |
| T-03-04-04 | Denial of Service (self-inflicted) | reconnect storm during sustained outage → IP-ban | mitigate | R5 storm cap: >10 reconnects/hour triggers DEGRADED_REST_POLLING state (no further reconnect attempts for 60s; emit Sentry warning). Test asserts cap fires. |
| T-03-04-05 | Denial of Service (memory) | Fat WS frame (>4 MiB) crashes daemon (Phase 02 D-23 OOM precedent) | mitigate | `max_size=2**22` (4 MiB) caps inbound frame size; PayloadTooBig exception caught + logged + connection cycles. Plan 02 fly-l2.toml memory=1024mb provides 256:1 headroom. |
| T-03-04-06 | Elevation of Privilege | malicious WS frame triggers code execution via unsafe deserialization | mitigate | Only `json.loads` is used; downstream consumer (Plan 06 mirror) treats payload as dict; no dynamic import; Plan 06 will further sanitize via supabase-py SDK. |
