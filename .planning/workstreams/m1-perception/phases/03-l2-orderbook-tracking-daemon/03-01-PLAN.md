<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions → public Supabase REST | secret-bearing curl from ephemeral runner; anon key only confers SELECT on RLS-protected tables |
| GitHub Actions → Better Stack heartbeat URL | public POST to opaque URL — secret only as obscurity; treated as low value |
| Repository contents | workflow file is public if repo is public; secrets remain encrypted in GH secret store |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01-01 | Information Disclosure | curl error output may leak full URL incl. JWT if `-v` is used | mitigate | Use `curl -fsS` (no `-v`); never echo response body when status ≠ 200; pipe stderr to /dev/null on success path |
| T-03-01-02 | Spoofing | anyone can post to BS heartbeat URL = false positive "alive" | accept | Heartbeat URL is per-monitor opaque; BS treats POST as liveness only; no auth gate. Risk = low-value (no data flow). |
| T-03-01-03 | Denial of Service | malicious push triggers `workflow_dispatch` repeatedly | accept | GHA concurrency group cancels duplicates; Supabase REST has its own rate-limit; cost capped at GH free-tier minutes |
| T-03-01-04 | Tampering | someone edits workflow to ping wrong endpoint | mitigate | Wave 0 YAML structural test (`tests/test_supabase_keepalive_yml.py`) asserts cron + secrets pattern. Pre-commit + CI must run this test. |
| T-03-01-05 | Repudiation | workflow ran but no record of which endpoint was pinged | mitigate | Step name `Ping Supabase REST` appears in GH run log; `gh run view <id> --log` retrievable for 90 days |
</threat_model>

    ```yaml
    name: Supabase Keepalive
    # D-01 (Phase 03): Supabase Free + daily GHA cron — reverse of RESEARCH §2.6 Pro recommendation.
    # Risk surface: 4-day idle pause → Better Stack heartbeat tolerance 25h catches GHA miss.
    # Phase 02 L8 precedent: GHA failure email alone is insufficient (4-day silent fail observed).
    on:
      schedule:
        - cron: "0 6 * * *"   # daily 06:00 UTC (region ams quiet hour)
      workflow_dispatch: {}   # manual probe
    
    concurrency:
      group: supabase-keepalive
      cancel-in-progress: false
    
    permissions:
      contents: read
    
    jobs:
      ping:
        name: ping supabase + heartbeat
        runs-on: ubuntu-latest
        timeout-minutes: 5
        steps:
          - name: Ping Supabase REST (smoke-loop)
            env:
              SUPABASE_URL: ${{ secrets.POLYARB_SUPABASE_URL }}
              SUPABASE_ANON_KEY: ${{ secrets.POLYARB_SUPABASE_ANON_KEY }}
            run: |
              for i in $(seq 1 10); do
                if curl -fsS \
                    "${SUPABASE_URL}/rest/v1/snapshots?limit=1" \
                    -H "apikey: ${SUPABASE_ANON_KEY}" \
                    -H "Authorization: Bearer ${SUPABASE_ANON_KEY}" \
                    -H "Accept: application/json" \
                    -o /dev/null
                then
                  echo "supabase reachable on attempt $i"; exit 0
                fi
                sleep 6
              done
              echo "supabase unreachable after 10 attempts (60s)" >&2; exit 1

          - name: Post Better Stack heartbeat (success path)
            if: success()
            env:
              BETTER_STACK_KEEPALIVE_HEARTBEAT_URL: ${{ secrets.BETTER_STACK_KEEPALIVE_HEARTBEAT_URL }}
            run: |
              if [ -z "${BETTER_STACK_KEEPALIVE_HEARTBEAT_URL:-}" ]; then
                echo "BETTER_STACK_KEEPALIVE_HEARTBEAT_URL not set — heartbeat skipped (CONFIGURE BEFORE GO-LIVE)" >&2
                exit 0
              fi
              curl -fsS -X POST "${BETTER_STACK_KEEPALIVE_HEARTBEAT_URL}" -o /dev/null

          - name: Alert on failure (GH email path)
            if: failure()
            run: |
              echo "::error::Supabase keepalive FAILED — pause clock NOT reset; expect /health degradation in 4 days"
              exit 1
    ```

    ```bash
    #!/usr/bin/env bash
    # check_keepalive.sh — list last 7 runs of supabase-keepalive workflow.
    # Surfaces silent failures + drift (Phase 02 L8 precedent).
    set -euo pipefail

    WORKFLOW="supabase-keepalive.yml"

      --jq '.[] | "\(.createdAt) \(.conclusion // "in_progress") #\(.databaseId) — \(.displayTitle)"'

    failure_count=$(gh run list --workflow "${WORKFLOW}" --limit "${LIMIT}" \

    success_count=$(gh run list --workflow "${WORKFLOW}" --limit "${LIMIT}" \
      --json conclusion --jq '[.[] | select(.conclusion == "success")] | length')

    echo "failures: ${failure_count} / successes: ${success_count} / total: ${LIMIT}"

    if [ "${failure_count}" -gt "1" ]; then

    fi
    ```
