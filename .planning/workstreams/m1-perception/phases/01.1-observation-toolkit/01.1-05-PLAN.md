       - 顶部 docstring 必含：
         * "yaml.safe_load — rejects !!python/object (T-01.1-19)"

         * "Whitelist nodes: Expression, Constant(numeric only), Name(in ALLOWED_VARS), UnaryOp(Not/USub), BinOp(+ - * /), Compare(< <= > >= == !=), BoolOp(And/Or)"

       - 模块常量：
         ```python
         _MAX_EXPR_LEN = 200

         # Warning #9 决议：完整别名 → 全名（或 computed）映射表
         # 用户在 alert_when 表达式中引用 key（左列），求值时映射到 row 字段（右列）。
         # spread 是 computed：ask - bid（仅在 bid/ask 都非 None 时才有效）。
         ALLOWED_VARS = {
             # 短别名 → row 字段
             "mid": "mid_price",
             "bid": "best_bid_price",
             "ask": "best_ask_price",
             "spread": "<computed: ask - bid; None if either side missing>",
             "liq": "liquidity_usd",
             "vol": "volume_usd",
             # 全名也接受（identity）
             "mid_price": "mid_price",
             "best_bid_price": "best_bid_price",
             "best_ask_price": "best_ask_price",
             "liquidity_usd": "liquidity_usd",
             "volume_usd": "volume_usd",
         }
         _BIN_OPS = {ast.Add: operator.add, ast.Sub: operator.sub,
                     ast.Mult: operator.mul, ast.Div: operator.truediv}
         _CMP_OPS = {ast.Lt: operator.lt, ast.LtE: operator.le,
                     ast.Gt: operator.gt, ast.GtE: operator.ge,
                     ast.Eq: operator.eq, ast.NotEq: operator.ne}
         ```

       - `_eval_node(node, env)` recursive AST walker — 处理上述白名单节点；**任何不匹配的 node 类型抛 `ValueError(f"AST node {type(node).__name__} not allowed")`**。Constant 检查 `isinstance(node.value, (int, float))`；Name 检查 id 在 ALLOWED_VARS（key set），值从 env 拿；BoolOp 短路求值；Compare 链式求值。
       - **None handling（Warning #9 决议）**：env build 阶段，若任一被引用变量（含 spread 的依赖 bid/ask）为 None，整个 evaluate_alert **返回 False + logger.warning + skip 该 entry**，不抛。这意味着 evaluate_alert 不会因数据缺失污染调用方逻辑——missing data ≠ alert triggered。
         * 实现细节：先扫描 AST 找所有引用的 Name.id（recursively collect names），再对每个 name 查它依赖的 row 字段：
           * `mid` / `mid_price` → row["mid_price"]
           * `bid` / `best_bid_price` → row["best_bid_price"]
           * `ask` / `best_ask_price` → row["best_ask_price"]
           * `spread` → 需要 bid 和 ask 都非 None；任一缺失 → skip（Warning #9 行为）
           * `liq` / `liquidity_usd` → row["liquidity_usd"]
           * `vol` / `volume_usd` → row["volume_usd"]
         * 任何引用变量在 row 中是 None → 该次求值返回 False + warning（不抛 ValueError）

       - `evaluate_alert(expression: str, market_row: dict) -> bool`：
         * 长度校验 `len(expression) <= _MAX_EXPR_LEN` 否则 ValueError
         * `tree = ast.parse(expression, mode="eval")`
         * 扫描表达式中所有 Name.id（仅允许 ALLOWED_VARS keys）
         * 用 ALLOWED_VARS 映射构造 env（含别名 + 全名）；**spread = ask - bid 仅当两者都非 None 才计算**，否则 spread → None
         * 任何被引用的 env 值为 None → return False + logger.warning（不抛）
         * 否则调 `_eval_node(tree, env)` 并 `bool(...)` 返回

       - `WatchlistEntry` dataclass(frozen=True)：slug / reason / alert_when / added

       - `load_watchlist(yaml_path)`：
         * 不存在 → 返回 []
         * `with open: data = yaml.safe_load(f) or []`
         * data 必须 list；遍历构造 WatchlistEntry
