### Task 2 — watchlist.py 受限 AST 表达式求值

**安全实现**（`src/polyarb/observation/watchlist.py`，230 行）。**关键不变量**：

| 不变量 | 实现 | 验证 |
|--------|------|------|
| **Python 内置 eval / exec NEVER 被调用** | watchlist.py 源码不含 `eval(` / `exec(` 字面量 | `test_no_python_eval_in_source`（字符串扫描） |
| **`yaml.safe_load` only** | `data = yaml.safe_load(...)`，无 `yaml.load(` | `grep -c 'yaml.load(' watchlist.py == 0` |
| **AST node whitelist** | `_ALLOWED_AST_NODES = frozenset({Expression, Constant, Name, UnaryOp, BinOp, Compare, BoolOp})`，其它 node 类型 → `ValueError` | `test_evaluate_alert_rejects_function_call`（`len(spread)` → ValueError）/ `_rejects_attribute`（`spread.real`） |
| **变量白名单** | `ALLOWED_VARS` 11 个 key 的 alias→column 映射表；`Name.id` 不在 keys → ValueError | `test_evaluate_alert_rejects_unknown_var`（`foo > 1` → ValueError） |
| **数值常量限定** | `Constant.value` 必须 `isinstance(value, (int, float))` | `test_evaluate_alert_rejects_string_constant`（`'malicious' < 1` → ValueError） |
| **DoS 长度上限** | `len(expression) > _MAX_EXPR_LEN(200)` → ValueError | `test_evaluate_alert_long_expression_capped` |
| **Warning #9 None-handling** | env build 阶段任一引用变量 (含 spread 的 bid/ask 依赖) 为 None → `return False` + `logger.warning`，**不抛** | `test_evaluate_alert_skips_when_bid_none` / `_when_ask_none` |
| **alias↔fullname 等价** | `mid` 与 `mid_price` 行为一致；`bid` 与 `best_bid_price` 同；spread 唯一 computed | `test_evaluate_alert_aliases_to_fullnames` |

**支持的表达式语法**（user-facing 总览）：

| 类别 | 允许 |
|------|------|
| 变量（短别名） | `mid` `bid` `ask` `spread` `liq` `vol` |
| 变量（全名 identity） | `mid_price` `best_bid_price` `best_ask_price` `liquidity_usd` `volume_usd` |
| 数值常量 | int / float（拒 string / list / dict） |
| 算术 | `+` `-` `*` `/`（拒 `**` `//` `%` `<<` `>>` 等位运算） |
| 比较 | `<` `<=` `>` `>=` `==` `!=`（含链式 `0.4 < mid < 0.6`） |
| 布尔 | `and` `or` `not`（短路求值） |
| 一元 | `-x`（USub）`not x`（Not） |
| **禁止** | 函数调用 / 属性访问 / 下标 / lambda / 推导式 / 任何其它 Python 语法 |

**`load_watchlist` 容错链**：

```
yaml 文件不存在        → return []
yaml.safe_load(...)    → 拒 !!python/object（ConstructorError）
顶层不是 list          → ValueError（"watchlist yaml must be a list of entries"）
单条 alert_when 求值失败 → logger.warning + alert_when=None（entry 保留，alert disable）
```

**`check_alerts` 运行时**：read-only sqlite + 逐 entry `WHERE slug = ?` 参数化；
slug 不在 db → warning + continue；表达式抛 ValueError → warning + continue；
返回 `[(entry, row_dict), ...]`，永不因单条数据问题抛错。

## Security invariants — 完整清单

| Threat ID | 缓解 | 验证 |
|-----------|------|------|
| **T-01.1-19** Tampering: watchlist.yaml `!!python/object` → 任意代码执行 | `yaml.safe_load`（不用 `yaml.load`） | `grep -c 'yaml.safe_load' watchlist.py >= 1`；`grep -c 'yaml.load(' == 0`；`test_load_watchlist_safe_load` 拒 `!!python/object` |

**额外不变量**（Warning #9 决议）：

- `evaluate_alert` 在引用变量为 None 时**返回 False + warning，不抛 ValueError**。
  这意味着：上游数据缺失（如 ghost_book → bid/ask 一侧为 None）不会让 watchlist
  alert 误触发，也不会让一条数据问题污染整个 batch 检查。语义不变量：
  **missing data ≠ alert triggered**。

## Decisions Made

详见 frontmatter `key-decisions` 段。最关键的 4 条：

1. **不调用 Python 内置 eval/exec** — 自写 AST walker 是受限 DSL 求值的"标准做法"，
   未来 m4 LLM 策略层、m2 套利过滤条件如果要让用户写表达式，应复用此模板。
2. **yaml.safe_load only** — 已经是项目级 invariant（plan 03 也用），watchlist 模块
   docstring + 测试双重保护。
3. **Warning #9 None-handling fail-soft** — 不让一条 ghost_book market 让整个
   `make watchlist-alerts` 命令失败。语义上更接近 SQL `WHERE x IS NULL` 的
   三值逻辑，而不是 Python `bool(None) == False`。
4. **Multi-source detail composition** — show-market 是 SQLite + DuckDB 两个存储
   引擎在单 CLI 命令里联动的第一个示例，模板可复用到 m2/m4 的 detail view。
