<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .env → TranslationConfig | API key 是 secret，绝不能 log/commit |
| TranslationClient → 外部 LLM endpoint | 通过 AsyncOpenAI HTTP，凭 SDK + httpx 默认安全（不 follow redirects） |
| LLM response → cache.upsert_batch | LLM 返回的 zh 是任意字符串，存 question_zh 不渲染（CLI 后端会 escape） |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01.1-04 | Information Disclosure | API key 误 log | mitigate | TranslationConfig.__repr__ 不打印 api_key（pydantic SecretStr）；启动期 logger.info 仅打印 model + base_url，**不打印 api_key** |
| T-01.1-05 | Tampering | LLM 返回的 question_zh 包含 SQL 注入 | mitigate | upsert_batch 一律参数化 SQL（`?`），不字符串拼 |
| T-01.1-06 | Information Disclosure | API key 进入 git（.env 误 commit） | mitigate | .gitignore 已含 `.env`（Phase 1 早建立）；本 plan 只新增 `.env.example` 模板（值是占位符） |
| T-01.1-07 | DoS | 用户 question 数 50000+，并发 10 → 短时打爆 LLM 配额 | mitigate | TRANSLATION_MAX_CONCURRENCY 默认 10 但暴露给 .env，**首次 sample-first guard 强制 50 条 dry-run**（Warning #8） |
| T-01.1-08 | Repudiation | 翻译失败的 question 静默丢失 | mitigate | retry_count++ → is_dead=1 标记，translation-stats 显示 dead count，不静默 |
</threat_model>

       ```python
       TransientError (recoverable — retry_count++ in cache):
         - APIConnectionError, APITimeoutError, RateLimitError(post-SDK-retry),
           InternalServerError, count_mismatch, empty_content

       Pattern: bracket each phase with `_phase` context (mirrors snapshot/orchestrator.py).
       """
       from openai import AuthenticationError, NotFoundError, BadRequestError

       class ConfigError(Exception):
           """Raised when translation config (api_key/model/base_url) is invalid.
           Standalone CLI must exit 1; snapshot orchestrator records reason but
           does NOT fail the snapshot (sidecar semantics)."""

       class TransientError(Exception):
           """Raised when translation hits a recoverable error after SDK retries.
           Caller logs WARNING; cache.increment_retry handles dead-letter."""

       _CONFIG_ERROR_BAD_REQUEST_CODES = frozenset({"invalid_api_key", "model_not_found"})

       async def translate_pending(
           cfg: TranslationConfig,
           db_path: Path,
           sample_limit: int | None = None,
       ) -> TranslateSummary:
           cache = TranslationCache(db_path)
           pending = cache.list_untranslated(limit=sample_limit)
           if not pending:
               logger.info("translate_pending: nothing to do")
               return TranslateSummary(translated=0, skipped=0, dead=0, total_tokens=0)

           summary = TranslateSummary(...)
           async with TranslationClient(...) as client:
               batches = [pending[i:i+cfg.batch_size]
                          for i in range(0, len(pending), cfg.batch_size)]
               for batch in batches:
                   hashes, ens = zip(*batch)
                   try:
                       result = await client.translate_batch(list(ens))
                       rows = [TranslationRow(...) for ...]
                       cache.upsert_batch(rows)
                       summary.translated += len(rows)
                       summary.total_tokens += result.prompt_tokens + result.completion_tokens
                   except AuthenticationError as e:
                       raise ConfigError(f"invalid api_key: {e}") from e
                   except NotFoundError as e:
                       raise ConfigError(f"model not found: {e}") from e
                   except BadRequestError as e:
                       code = getattr(e, "code", None) or (e.body or {}).get("error", {}).get("code")
                       if code in _CONFIG_ERROR_BAD_REQUEST_CODES:
                           raise ConfigError(f"bad request (config invalid): {e}") from e
                       # 其它 BadRequest（prompt-level 错误）→ TransientError 走 retry++
                       logger.warning(f"batch BadRequest (non-config): {e!r}")
                       cache.increment_retry(list(hashes))
                       summary.skipped += len(batch)
                   except Exception as e:
                       logger.warning(f"batch failed (will mark retry): {e!r}")
                       cache.increment_retry(list(hashes))
                       summary.skipped += len(batch)
           summary.dead = cache.count_dead()
           return summary
       ```
