## User first-run recommended flow

```bash
# 1. Set up .env from template
cp .env.example .env
$EDITOR .env   # fill in TRANSLATION_API_BASE / API_KEY / MODEL

# 2. Sample-first dry run (50 questions to verify .env)
make translate-pending-sample

# 3. Inspect the result
make translation-stats
sqlite3 data/state.db "SELECT COUNT(*) FROM question_translations WHERE is_dead=1"

# 4. If sample looks good, bulk-translate everything
make translate-pending FORCE=1

# 5. (After future snapshots) re-translate just the new questions
make translate-pending FORCE=1
```

The first invocation without FORCE / --limit will be REJECTED by the sample-first guard with a friendly stderr message — this protects against burning tokens on a misconfigured .env.

## Deviations from Plan

**Auto-fixed bugs:**

1. **[Rule 1 - Bug] cache.list_untranslated excluded retry placeholders**
   - **Found during:** Task 2, `test_translate_pending_marks_dead_after_4_retries`
   - **Issue:** After `insert_retry_placeholders` writes a row with `question_zh=''`, subsequent `list_untranslated` calls excluded that row (`qt.question_hash IS NULL` is false). This meant retry attempts 2-4 found nothing to retry, never bumped retry_count past 1, never reached is_dead=1.
   - **Fix:** Added second OR branch: `OR (qt.question_zh = '' AND qt.is_dead = 0)` so placeholders with empty zh + alive remain in the untranslated pool. Documented invariant in cache.py docstring.
   - **Files:** `src/polyarb/translation/cache.py:list_untranslated`
   - **Commit:** a037043 (Task 2)

2. **[Rule 1 - Bug] test_client_module_does_not_import_tenacity false positive**
   - **Found during:** Task 2, running test_translation_client
   - **Issue:** Initial test asserted `"tenacity" not in src` which matched documentation comments mentioning the anti-pattern.
   - **Fix:** Tightened the gate to scan only for actual `import tenacity` / `from tenacity` lines, allowing the word in docstrings/comments (we WANT to document the anti-pattern).
   - **Files:** `tests/m1-perception/test_translation_client.py:test_client_module_does_not_import_tenacity`
   - **Commit:** a037043 (Task 2)

**Auto-added critical functionality:**

3. **[Rule 2 - Critical] _overwrite_placeholders helper in translator.py**
   - **Why:** `INSERT OR IGNORE` skips existing PK, so on the success path the placeholder's `question_zh=''` would never be overwritten with the real translation.
   - **Fix:** Added `_overwrite_placeholders` that runs INSERT OR IGNORE first (covers fresh path) then UPDATE on `question_zh=''` placeholders (covers placeholder-overwrite path). Resets retry_count=0 + is_dead=0 on success so a previously-failed question that just succeeded becomes alive.

**Plan deviations explicitly retained from CONTEXT-AMENDMENT-01:**

- Used `uv run` everywhere (not raw `pip install` / `python -m`) — Makefile and tests honor uv-aware workflow.
- openai dependency was already in pyproject.toml (commit 20416ed), not added.
