## Locked decisions

- The worker runs on the L1 `app` machine because only that machine owns the
  SQLite volume read by the HTTP route.
- It runs immediately, then 120 seconds after each terminal attempt.
- The route quote SLA remains 300 seconds; health warns at 240 seconds and
  fails above 300 seconds.
- Ordinary collection failure is fail-soft; cancellation propagates.
- Durable quote-run leases plus the single loop prevent overlap.
- Local/test default is disabled; `fly.toml` explicitly enables production.
- Production acceptance requires at least three complete runs and repeated
  HTTP 200 observations spanning more than one interval.
- Output remains gross-before-fees, known-universe discovery only.
