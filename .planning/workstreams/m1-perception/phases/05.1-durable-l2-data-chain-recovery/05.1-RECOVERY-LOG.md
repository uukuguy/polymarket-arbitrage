| Invariant | PASS threshold |
|---|---|
| L2 process continuity | machine ID, instance/start anchor, and `created_at` stay unchanged for the entire proof |
| LISTEN recovery | connection returns to `listening` and `reconnect_count` strictly increases within 180 seconds |
| Poll causality | after a newer L1 snapshot appears, committed cursor reaches it within **60 seconds** |
| Notification exclusion | `event_bus:last_notification_at` is byte-for-byte/numerically exactly unchanged across the poll-only transition |
| Stale grace | cursor/reconciliation strict failure grace remains **180 seconds**; it is not relaxed for this proof |
| L1 cleanup | `POLYARB_EVENT_BUS_ENABLED=1` is observed after the poll test and a later notification advances the exact anchor |
| Candidate projection | active durable `(asset_id, recipe_name)` keys equal desired keys; WS assets equal unique desired asset IDs |
| Upstream health | strict `/health` returns HTTP 200 for repaired upstream checks; pre-existing L3 is recorded separately |

Any unmet invariant is `RECOVERY FAIL`. Do not restart L2 to turn it into a pass,
and do not change L3's strict N=5 thresholds.
