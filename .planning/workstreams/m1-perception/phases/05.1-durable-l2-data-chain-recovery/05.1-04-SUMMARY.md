## Deviations from Plan

### Closure-invalidating regression was fixed before sign-off

The first valid quiet-refresh proof was not treated as final because the fresh
post-proof check found an empty projection and strict HTTP 503. Root-cause work,
test isolation, fail-closed guards, natural recovery, and a second acceptance
window were added to Plan 04. This enlarged the verification surface but did not
change production thresholds or perform an unapproved deployment.

### Runtime guards remain undeployed

The L1/L2 empty-projection guards are locally verified defense-in-depth, not
claimed as deployed behavior. Phase closure is justified because the production
regression source was the local test runner; that source is removed locally, and
the unchanged deployed chain naturally recovered and re-passed acceptance.
