# Quiet-Market Book Refresh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use subagent-driven-development or inline execution to implement this plan task-by-task. Steps preserve RED -> GREEN checkpoints.

**Goal:** Keep strict WS and mirror freshness truthful for live-but-quiet candidate markets without reconnecting or changing thresholds.

**Architecture:** A single L2 background task observes real business-frame age and sends a rate-limited dynamic `subscribe` with `initial_dump=true` for the current candidate/L3 union. The send never marks freshness; returned frames continue through the existing receive and mirror chain.

**Tech Stack:** Python 3.12, asyncio, websockets 15+, pytest/pytest-asyncio, uv, Fly.io.

</objective>

<interfaces>
- `WsConsumer.request_book_refresh() -> bool`: send one dynamic subscribe payload for the sorted current candidate/L3 union; return false for empty/no socket/send failure; mutate no subscription or freshness state.
- `WsConsumer.refresh_if_quiet(*, now_s: float | None = None, quiet_after_s: float = 60.0, retry_s: float = 30.0) -> bool | None`: return `None` when not due, otherwise record the attempt before awaiting send and return the send result.
- `WsConsumer.run_quiet_refresh(stop_event: asyncio.Event, *, quiet_after_s: float = 60.0, retry_s: float = 30.0, check_interval_s: float = 5.0) -> None`: bounded loop around `refresh_if_quiet`; propagate cancellation.
</interfaces>
