## Decisions Made

- **`FLY_API_TOKEN=` applied to ALL flyctl, not just chaos-l2-***: deploy / tail-logs / fly-l2-status / fly-l2-logs all hit the same .env-shadowing class of risk; making the prefix universal removes the "is this site exempt?" cognitive overhead from future edits.
- **Double protection on recipes that source .env**: explicit `unset FLY_API_TOKEN;` after `set +a` PLUS `FLY_API_TOKEN=` prefix on the same logical line. Either alone would suffice; both means a broken backslash continuation or future refactor can't silently regress.
- **chain-truth as a thread-level (§1.6) rule, not phase-local**: all future phases need this discipline; thread-level placement makes it inherit-by-default. Cross-ref from §1 (production-grade criteria) so the relationship is visible.
- **CLAUDE.md kept tight (+27 lines)**: file was already at 243 lines (over 200 soft warning). Heavy content sits in linked thread §1.6 + `docs/dev/chaos-toolkit.md`; CLAUDE.md only carries trigger + pointer. Total now 270 lines — still over soft limit but lighter than putting matrices inline would have been.
- **`command -v` over `which`**: image-check target uses POSIX `command -v` since `which` itself is one of the MISS tools in slim images (would have been self-defeating).
