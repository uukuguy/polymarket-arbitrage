    1. In src/polyarb/snapshot/orchestrator.py add helper function near top of file (after imports):
       ```python
       def _derive_notes_from_issues(issues: list[Issue]) -> str | None:
           """Pull fail-reason summary from L1/L4 API_UNREACHABLE issues for snapshots.notes.

           Returns None when no issues warrant operator attention. Otherwise produces
           a semicolon-separated `Source: ErrorClass: msg` string, truncated to 200 chars.
           Format chosen so SQL can `SELECT notes, count(*) FROM snapshots GROUP BY substr(notes,1,40)`.
           """
           from polyarb.validator.category import Category  # local import to keep top clean
           reasons: list[str] = []
           for issue in issues:
               if issue.category != Category.API_UNREACHABLE:
                   continue
               # issue.detail looks like "Gamma unreachable: ConnectError(...)" — keep first 80 chars
               reasons.append(issue.detail[:80] if issue.detail else f"L{issue.layer}: unknown")
           if not reasons:
               return None
           joined = "; ".join(reasons)
           return joined[:200]
       ```
