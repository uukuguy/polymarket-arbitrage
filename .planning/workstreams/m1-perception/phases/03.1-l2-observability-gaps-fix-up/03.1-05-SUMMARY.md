## Decisions Made
- `AliasChoices("sentry_environment", "POLYARB_SENTRY_ENV")` — supports both kwarg-by-name (for Settings(sentry_environment="staging") in tests) AND env-var-by-alias (POLYARB_SENTRY_ENV without the long `_ENVIRONMENT` suffix)
- W-6 typo guard: warn not refuse — refusing would block legitimate custom env names (e.g. `perf-test`, `eu-staging`); warning preserves opt-in while surfacing typos at boot
- Defer Sentry alert rule changes — invasive multi-step config that the plan's autopilot scope explicitly carves out for user review
