<context>
Current code ignores `False` from `add_subscriptions`/`remove_subscriptions`, mutates the offline L3 set as if it were committed, resolves one shared quiet-refresh Future after the first asset, and returns only TOB mirror success from `make_l2_event_handler`. This plan removes those four truth gaps without changing the N=5 recipe or dry-run isolation.

Stable interfaces after this plan:

- `WsMembershipSnapshot(generation: int, desired: frozenset[str], committed: frozenset[str], evidenced: frozenset[str], evidenced_at: Mapping[str, datetime])`.
- `WsConsumer(..., membership_observer: Callable[[WsMembershipSnapshot], None] | None = None)`; `set_l3_desired(asset_ids: Iterable[str]) -> None`, `l3_membership_snapshot() -> WsMembershipSnapshot`, and private `_publish_l3_membership_locked() -> None`. Every desired/control/generation/evidence transition publishes one immutable snapshot before returning; `l2_main` wires the observer directly to `L3EvidenceRuntime.update_membership`. Sampler and health read runtime only.
- `WsConsumer.add_subscriptions(asset_ids: list[str]) -> bool` and `remove_subscriptions(...) -> bool` mutate committed state only after a successful current-generation control; offline paths return false and leave committed state unchanged.
- `WsConsumer.record_book_evidence(*, asset_id: str, generation: int, book_levels_succeeded: bool, observed_at: datetime) -> None` accepts current-generation depth evidence only.
- `FrameDispatchResult(tob_written: bool, book_levels_written: bool, observed_at: datetime | None)`; `make_l2_event_handler(...) -> Callable[[dict], FrameDispatchResult]`.
- `PromoteRunResult(status: PromoteStatus, reason_code: str, desired: frozenset[str], committed: frozenset[str], evidenced: frozenset[str], run_seq: int, scheduled_at: datetime)`.
- Production `promote_run(..., evidence_store: L3EvidenceStore | None = None, evidence_runtime: L3EvidenceRuntime | None = None, scheduled_at: datetime | None = None, run_seq: int | None = None, apply_mutations: bool = True) -> PromoteRunResult`; optional evidence dependencies are allowed only for mutation-free dry-run compatibility.
- Every direct PostgreSQL dependency owned by `l2_main`—cursor reconciliation, LISTEN, promoter reads/writes, and the L3 evidence store—uses `settings.l2_runtime_db_dsn`. `settings.supabase_db_dsn` remains migration-only and is never read by the L2 daemon path. Missing/rejected runtime credentials keep `/healthz` available but make strict evidence health fail closed; no owner/service/retention fallback is permitted.
</context>
