## Sampling Rate

- **After every task commit:** Run that task's exact focused pytest command.
- **After every plan wave:** Run the union of focused tests plus touched-file Ruff
  and compile checks; run the full suite at each sequential wave boundary.
- **Before `$gsd-verify-work`:** Full suite, `make planning-status`, image-aware
  chaos check, and M1 manual contract must be green.
- **Max feedback latency:** 60 seconds for focused tests; no three consecutive
  tasks may depend on manual-only evidence.
