## Decisions Made

- Treat `scheduled_at` and `sampled_at` as different clocks. Schedule identity
  is an exact boot grid; actual observation time alone drives gap/freshness.
- Reject event kinds independently of mutable severity. An exception must be
  fixed in the immutable pre-T0 manifest and therefore changes the hashes.
- Use one pre-T0 `soak_manifest_bound` database event with exact UUID, sequence,
  kind, detail, identity, and server time. Lost ACK retries must read back an
  identical row rather than append a second binding.
- Prove runtime and retention credentials through effective capabilities,
  recursive membership, strong TLS, RLS enablement/policies, and forbidden
  role/object exclusions. Neither proof command prints a DSN or secret.
- Preserve workflow path observability but prevent a merge from deploying.
  Production rollout remains Plan 05 and requires explicit approvals.
