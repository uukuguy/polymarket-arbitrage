**Goal**: 老 DB 启动一次后 `snapshots` 表必含 `supabase_mirror_at_ms` BIGINT 和 `parquet_r2_url` TEXT 两列。

**Files**:

- `tests/m1-perception/test_sqlite_store_migration.py` — NEW regression test

**Steps**:
1. 在 `init_schema()` 内，CREATE TABLE 完成后追加 idempotent migration block:
   ```python
   # Idempotent column-add for legacy DBs (Plan 02-08 F-01).
   # CREATE TABLE IF NOT EXISTS skips column changes; we use PRAGMA + conditional ALTER.
   def _ensure_column(table: str, column: str, ddl: str) -> None:
       row = conn.execute(f"PRAGMA table_info({table})").fetchall()
       names = {r[1] for r in row}
       if column not in names:
           conn.execute(f"ALTER TABLE {table} ADD COLUMN {column} {ddl}")
           logger.info(f"sqlite_store: ALTER {table} ADD COLUMN {column}")

   _ensure_column("snapshots", "supabase_mirror_at_ms", "INTEGER")
   _ensure_column("snapshots", "parquet_r2_url",        "TEXT")
   ```
2. 注意：列定义 DDL 要跟 `SNAPSHOTS_DDL` 中对应列字符串一致（去掉 NOT NULL/默认值，因为加列时所有老行必须 NULL — `INTEGER`/`TEXT` 默认 NULL OK）。
3. New test `test_sqlite_store_migration.py::test_legacy_db_adds_new_columns`:
   - Setup: 创建 fresh DB, CREATE 一个**手工模拟老版** snapshots 表（没新两列）
   - Action: 调用 `SQLiteStore(path).init_schema()`
   - Assert: PRAGMA 现在含两列；INSERT/SELECT 新两列工作

**Steps**:
1. `scheduler.py::run()` 把 inner sleep 从 10s 改 1s:
   ```python
   while elapsed < interval_s and not stop_event.is_set():
       await asyncio.sleep(min(1, interval_s - elapsed))

   ```
2. 调查 `_tick()` 是否会因为 `await self._run_snapshot()` 阻塞过久（snapshot 一次可能跑数十秒）。让 `_tick` 包 cancellation-aware：
   ```python
   try:
       result = await self._run_snapshot()
   except asyncio.CancelledError:
       logger.info("scheduler tick cancelled mid-flight")
       raise
   ```
3. `main.py::main()` 末尾 gather 加 timeout:
   ```python
   await asyncio.wait_for(
       asyncio.gather(server_task, scheduler_task, return_exceptions=True),

   )
   ```

