def _dispatch_on_snapshot(payload: dict) -> None:

### G-03 — `src/polyarb/http/control.py` (THE HMAC analog to copy)

**This file is the template — do NOT re-invent HMAC.** Copy the middleware + auth-gate shape verbatim into the
new L2 admin route. Per D-03.2 the new endpoint is `POST /admin/chaos/ws-test-kill`, HMAC-gated by
`POLYARB_SCAN_SHARED_SECRET` (same secret pattern, `hmac.compare_digest` constant-time).

**Imports pattern** (`control.py:41-51`):

```python
from __future__ import annotations
import hashlib
import hmac
from typing import Any
from starlette.middleware.base import BaseHTTPMiddleware
from starlette.requests import Request
from starlette.responses import JSONResponse
```

**HMAC auth-gate function** (`control.py:54-100`) — the path-guard + compare_digest + body re-inject pattern.
The new L2 endpoint needs the same shape but guarding `/admin/` (not `/control/`):

```python
async def control_auth_middleware(request, call_next, *, secret):
    if not request.url.path.startswith("/control"):   # → "/admin" for G-03
        return await call_next(request)
    received_sig = request.headers.get("X-Signature")
    if not received_sig:
        return JSONResponse({"error": "missing X-Signature header"}, status_code=401)
    if received_sig.startswith("sha256="):
        received_sig = received_sig[len("sha256=") :]
    body = await request.body()
    expected_sig = hmac.new(secret.encode("utf-8"), body, hashlib.sha256).hexdigest()
    if not hmac.compare_digest(received_sig, expected_sig):   # constant-time
        return JSONResponse({"error": "invalid X-Signature"}, status_code=401)
    async def _receive() -> dict:                              # re-inject consumed body
        return {"type": "http.request", "body": body, "more_body": False}
    request._receive = _receive  # type: ignore[assignment]
    return await call_next(request)
```

**Middleware class adapter** (`control.py:103-118`) — Starlette `Middleware()` factory needs a class; secret captured at construction:

```python
class ControlAuthMiddleware(BaseHTTPMiddleware):
    def __init__(self, app, secret):
        super().__init__(app)
        self._secret = secret
    async def dispatch(self, request, call_next):
        return await control_auth_middleware(request, call_next, secret=self._secret)
```

**Route handler shape** (`control.py:121-162`) — the `unpause` handler reads `request.app.state.*`, mutates, returns JSONResponse.
G-03's handler reads the toggle from request body (D-03.5 `{"enabled": true/false}`) and flips the process-local flag.

**Planner discretion** (D-03.4/D-03.5): the new endpoint can live in a small new module (`src/polyarb/http/l2_control.py`)
mirroring control.py, OR be inlined; the HMAC middleware can be **imported and reused directly** from
`polyarb.http.control` since its path-guard is parameterizable only by editing — note the guard is hard-coded to
`/control`, so G-03 either (a) registers the endpoint under `/control/...` to reuse `ControlAuthMiddleware` unchanged,
or (b) writes a thin `/admin`-guarded variant. Planner decides. Reusing under `/control/chaos/ws-test-kill` is the
zero-new-middleware path.

## Shared Patterns

### HMAC admin endpoint (G-03)
**Source:** `src/polyarb/http/control.py:54-118` (`control_auth_middleware` + `ControlAuthMiddleware`)
**Apply to:** the new `/control/chaos/ws-test-kill` (or `/admin/...`) route on L2.

re-inject consumed body for downstream handler.

### /health sub-check triple (G-04)
**Source:** `src/polyarb/http/l2_health.py:178-186` (informational) and `:353-362` (severity-coupled)
**Apply to:** new `process:rss_kb` sub-check.
`{componentId, componentType, observedValue, observedUnit, status, output, time: _utc_now_iso()}`. Informational
checks omit `_severity`; thresholded checks call `overall = _severity(overall, status)`.

### Fail-soft envelope on /health reads (G-04) + chain-truth (G-02/G-04)
**Source:** `l2_health.py:173-177` (try/except → safe default) + `l2_candidate_refresh.py:75-92` (`_record_fetch_success` / `get_last_fetch_success_at_s` write-side-truth getter)
**Apply to:** all new /health sub-checks. Per `feedback_code-vs-chain-truth-2026-05`: a sub-check MUST read a field
the write-side REALLY mutates (RSS reads live `psutil.Process()`, not a config flag; prime fetch surfaces through the
existing `_last_fetch_success_at_s` field — no new dead-code gate).

### Process-local chaos flag (G-03)
**Source:** `ws_consumer.py:59-68` (`_check_ws_test_kill`) + `l2_health.py:375-387` (`chaos:ws_test_kill_flag` surface)
**Apply to:** the runtime flag flip. The /health chaos surface at §375 currently reads `os.getenv` — after G-03 it
should read the same process-local flag so the surface reflects an in-flight toggle, not just the cold-start env.
**Prod safety invariant:** `fly-l2.toml`/`fly.toml` MUST NOT set `POLYARB_WS_TEST_KILL` (CI-enforced).
