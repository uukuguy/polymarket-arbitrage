```python
async def scan_auth_middleware(request: Request, call_next: Any, *, secret: str) -> Any:
    if request.url.path != "/scan":
        return await call_next(request)
    received_sig = request.headers.get("X-Signature")
    if not received_sig:
        return JSONResponse({"error": "missing X-Signature header"}, status_code=401)
    if received_sig.startswith("sha256="):
        received_sig = received_sig[len("sha256="):]
    body = await request.body()
    expected_sig = hmac.new(secret.encode("utf-8"), body, hashlib.sha256).hexdigest()
    if not hmac.compare_digest(received_sig, expected_sig):
        return JSONResponse({"error": "invalid X-Signature"}, status_code=401)
    # re-inject body
    async def _receive() -> dict:
        return {"type": "http.request", "body": body, "more_body": False}
    request._receive = _receive  # type: ignore[assignment]
    return await call_next(request)
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet → daemon HTTP (Fly proxy) | 任意 client 可 POST /control/unpause; HMAC 是唯一闸门 |
| daemon HTTP → scheduler state | handler 直接调 scheduler.unpause(), 不过额外 ACL |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.1-8-01 | Spoofing | ControlAuthMiddleware HMAC | mitigate | `hmac.compare_digest` (constant-time, stdlib) + missing-header → 401 (RESEARCH Pitfall 1 reference; ASVS V4) |
| T-02.1-8-02 | Elevation of Privilege | /control/unpause (unauthorized unpause) | mitigate | HMAC-SHA256 of body with `POLYARB_SCAN_SHARED_SECRET` (per D-22, 同 /scan level); secret 走 Fly secret store |
| T-02.1-8-03 | Tampering | Timing oracle on HMAC compare | mitigate | `hmac.compare_digest` (constant-time); 禁止 `==` |

    unpause-prod:
    	@[ -n "$$POLYARB_SCAN_SHARED_SECRET" ] || (echo "ERROR: POLYARB_SCAN_SHARED_SECRET not set"; exit 1)
    	@SIG=$$(printf '' | openssl dgst -sha256 -hmac "$$POLYARB_SCAN_SHARED_SECRET" | awk '{print $$2}'); \
