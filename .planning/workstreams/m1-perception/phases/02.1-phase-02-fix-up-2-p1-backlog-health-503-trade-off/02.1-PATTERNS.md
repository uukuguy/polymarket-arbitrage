**HMAC middleware pattern** (`scan.py` lines 92-139):
```python
async def scan_auth_middleware(request: Request, call_next: Any, *, secret: str) -> Any:
    if request.url.path != "/scan":
        return await call_next(request)          # ← path guard: bypass all other routes

    received_sig = request.headers.get("X-Signature")
    if not received_sig:
        return JSONResponse({"error": "missing X-Signature header"}, status_code=401)

    if received_sig.startswith("sha256="):
        received_sig = received_sig[len("sha256="):]

    body = await request.body()
    expected_sig = hmac.new(secret.encode("utf-8"), body, hashlib.sha256).hexdigest()

    if not hmac.compare_digest(received_sig, expected_sig):   # ← constant-time
        return JSONResponse({"error": "invalid X-Signature"}, status_code=401)

    async def _receive() -> dict:
        return {"type": "http.request", "body": body, "more_body": False}
    request._receive = _receive  # type: ignore[assignment]

    return await call_next(request)
```
Mirror this verbatim for `control_auth_middleware`. Change the path guard from `!= "/scan"` to `not request.url.path.startswith("/control")`. Inline the same 3-line HMAC logic — do NOT import from `scan.py` (keep modules independent per RESEARCH.md Area 3 recommendation B).

**BaseHTTPMiddleware wrapper pattern** (`app.py` lines 28-41):
```python
class ScanAuthMiddleware(BaseHTTPMiddleware):
    def __init__(self, app: Any, secret: str) -> None:
        super().__init__(app)
        self._secret = secret

    async def dispatch(self, request: Any, call_next: Any) -> Any:
        return await scan_auth_middleware(request, call_next, secret=self._secret)
```
Mirror exactly as `ControlAuthMiddleware`. Replace `scan_auth_middleware` call with `control_auth_middleware`.

**Handler pattern** (`scan.py` lines 33-89, simplified for control):
```python
async def unpause(request: Request) -> JSONResponse:
    scheduler = request.app.state.scheduler      # ← access via app.state
    if scheduler.state != SchedulerState.PAUSED:
        return JSONResponse(
            {"status": "already_running", "state": scheduler.state.value},
```

## Shared Patterns

### HMAC Authentication
**Source:** `src/polyarb/http/scan.py` lines 92-139
**Apply to:** `src/polyarb/http/control.py` (`ControlAuthMiddleware` + `control_auth_middleware`)
```python
# Core HMAC validation — inline this 3-line block in control_auth_middleware:
body = await request.body()
expected_sig = hmac.new(secret.encode("utf-8"), body, hashlib.sha256).hexdigest()
if not hmac.compare_digest(received_sig, expected_sig):
    return JSONResponse({"error": "invalid X-Signature"}, status_code=401)
# After auth: re-inject body so downstream handler can read it
async def _receive() -> dict:
    return {"type": "http.request", "body": body, "more_body": False}
request._receive = _receive  # type: ignore[assignment]
```
**Critical:** use `hmac.compare_digest` (constant-time). Never use `==` for HMAC comparison (timing oracle).

### Starlette BaseHTTPMiddleware Class Wrapper
**Source:** `src/polyarb/http/app.py` lines 28-41
**Apply to:** `app.py` adding `ControlAuthMiddleware`; `control.py` defining `ControlAuthMiddleware`
```python
class ScanAuthMiddleware(BaseHTTPMiddleware):
    def __init__(self, app: Any, secret: str) -> None:

        self._secret = secret

    async def dispatch(self, request: Any, call_next: Any) -> Any:
```

Starlette's `Middleware()` factory requires a class. The adapter bridges a functional async middleware to the class interface. Secret passed at construction time from `settings.scan_shared_secret.get_secret_value()`.
