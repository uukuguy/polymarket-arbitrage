<objective>
Persist the local M2 paper account and open-position lifecycle so independent
`run`, `status`, and `close` CLI processes share crash-consistent state.

Purpose: remove the last process-local break in the Phase 2 lifecycle before
real venue integration, without changing execution economics or adding external
credentials/infrastructure.

Output: a repository-backed `PositionTracker`, stable idempotent execution
operations, configurable SQLite CLI state, true subprocess tests, Makefile
surfaces, and a teaching document.
</objective>
